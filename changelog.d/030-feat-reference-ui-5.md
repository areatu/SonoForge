- `feat(reference)`: UI-5 PR-2 — окно справочника S1 (немодальное, в стиле заголовка Windows 11; спека редизайна §4.7, §8.5; UD-06, UD-14, UQ-03, UA-13). **Модель в домене.** Новый модуль `domain/services/reference_topics.py` считает всё, что показывает окно, и не знает про Qt: `TopicEntry` (slug, имя, число параметров), `ReferenceRow` (параметр, полное имя, единица, норма для пола, градации, чип), `TopicView` (тема, чипы-подгруппы, строки, источник, рисунки, «Как измерять»), `build_topic_view(topic, sex, language)`, `search_view(query, language)` (по теме, параметру, синониму и полному названию; пустой запрос — все темы), `reference_values(projection)` (значения пациента по каталожным id из проекции исследования), `format_cut` (`36-51`, `≥ 62` — без потери нулей), `gradation_key` / `gradation_rank`, `chip_label` и `parameter_matches(query, language)` для палитры. Справочник читается тем же store, что и конструктор, с кэшем на четыре темы (`_cached_store`, `clear_cache` — после конструктора окно перечитывает данные). Честные ответы: нормы для пола нет — прочерк, а не догадка; значения нет — колонка «ПАЦИЕНТА» пуста, норма остаётся. **Окно.** `presentation/reference_window.py` — `ReferenceWindow(QDialog)`: слева 18 тем с поиском и счётчиком параметров (первая группа — сосуды), в центре крошки «Сердце › Левый желудочек», заголовок темы, чипы подгрупп, переключатель «Мужчины / Женщины / Оба», строка привязки «выбрано по пациенту · 59 лет», переключатель «Значения пациента» и таблица (параметр, единица, норма для пола, колонки градаций, колонка «ПАЦИЕНТА» с цветом градации), справа рисунок со счётчиком «1 / 2» и стрелками, «Как измерять» и «Источник», в подвале «Конструктор…» и «Источники» — окно только просит (`constructor_requested` / `sources_requested`), диалоги остаются у `MainWindow`. Одна копия на приложение (`_CACHED_WINDOW`, `show_reference_window`, `reset_reference_window`), Esc прячет окно вместо удаления, `Ctrl+F` ставит фокус в поиск, геометрия хранится в `qsettings_for("sonoforge", "reference-window")`. Цвета — только токены активной темы, градации — из `reference_grades` (владелец — UI-5). **Точки входа.** `MainWindow._open_reference_dialog(param_id=None, *, open_document=False)`: без параметра и в doc-режиме остаётся прежний `AseReferenceDialog` («Справочник» в строке, «Руководство» в меню), с параметром открывается окно S1 сразу на строке (`open_at`). `_open_reference_window` привязывает пациента: пол — из `_report_patient_info` (`ж`/`f` → female, `м`/`m` → male), возраст — через `_age_of`, значения — `reference_values(build_study_projection(snapshot))` из одного снимка состояния. При смене языка окно сбрасывается (`_reload_ui_language` → `_reset_reference_window`: окно строится на языке открытия), при смене темы перекрашивается (`_apply_theme` → `_refresh_reference_window_theme`), «Конструктор…» открывает прежний конструктор и перечитывает справочник. `Ctrl+K`: `command_catalog.reference_commands(query, language)` добавляет группу «Справочник» (`Command.label_text`, действие `reference_param:<id>`, `REFERENCE_PARAM_PREFIX`), палитра подмешивает её только при непустом запросе, `_run_command` понимает префикс — «Справочник: КДР» открывает окно на параметре. **Локали.** +37 ключей `ref_window.*` в RU и EN, паритет 2356 сохранён. **Проверки.** Храповик литералов: 210 → **210** (окно на токенах; два мёртвых `.replace("#000000"…)` / `.replace("#706f6f"…)` для SVG в окне удалены — в `resources/references/images` только png/jpg; пофайловый baseline выровнен `--update` без роста общего числа: палитра градаций, перенесённая в PR-1, теперь записана за `reference_grades.py`, а не за `structured_reference_widget.py`).
