- `ci(gui, tests)`: #310 / S3-01 — Windows/macOS GUI-smoke и regression/migration в CI. Обязательный граф PR пополнился тремя джобами. **`test-gui-smoke (windows-latest / macos-latest)`**: новый маркер `gui_smoke` (дополнительно к `gui`) на 27 отобранных быстрых самодостаточных сценариев по семи семействам — вкладки/открытие исследования (`test_main_window_tabs`, 5), линейный калипер (`test_linear_caliper_click_click`, 3) и перетаскивание узлов (`test_caliper_node_drag`, 2), контурная площадь (`test_area_contour_click_gesture`, 2), допплер-калипер (`test_caliper_doppler_and_repeat`, 3), экспорт отчёта (`test_report_export`, 3), раскладка (`test_layout_settings`, 3) и пользовательские настройки (`test_presentation_user_preferences_dialog`, 3), диалог экспорта DICOM (`test_dicom_export_dialog`, 3). Джоба гоняет `-m gui_smoke` на нативных рантаймерах с дефолтным Qt-плагином; collect-guard падает при выборке < 20 тестов, так что smoke не может незаметно сжаться. **`test-regression-migration (ubuntu-latest)`**: `tests/regression/` + `tests/migration/` (160 тестов, golden/snapshot и схемные миграции; без GPU/PACS/моделей; пустая выборка — провал pytest exit 5) теперь на каждом PR, раньше — только вручную. Медленные/интерактивные сценарии в smoke не входят (маркер `interactive` исключён addopts, отбор — только fast-тесты). **Проверки**: сборка `-m gui_smoke` = 27; в песочнице 20/27 проходят, 7 MainWindow-тестов падают только на font-артефакте minimal-плагина (эти же тесты зелёные в Linux GUI-шардах на main; нативные рантаймеры подтверждают в CI); regression/migration локально 160 passed за 1.4 с; baseline-гейт без изменений (маркеры не меняют инвентарь); ruff чист. Документация: раздел «Кросс-платформенный GUI-smoke (S3-01)» в `tests/README.md`/`README_RU.md`.
