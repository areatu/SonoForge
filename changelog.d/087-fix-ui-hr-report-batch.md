- `fix(ui, hr, report)`: пакет правок по отчёту пользователя — разблокировка окна после «Продолжить работу», авто-ЧСС и D/S-маркеры по запечённой ЭКГ, кнопки инструментов «в правой панели», позиция листа отчёта, диалог FPS и отступы иконок меню.

  **Windows 10, «Продолжить работу».** Qt пере-включает родительское окно при `hide()` только пока окно ещё модально; старый порядок (сначала `setWindowModality(NonModal)`, потом `hide()`) навсегда оставлял HWND родителя выключенным — звук блокировки на каждом клике, мёртвые кнопки, невозможность открыть новые исследования, выход через диспетчер задач. Теперь окно скрывается до смены модальности; нативный регрессионный тест проверяет `IsWindowEnabled`, тест порядка — порядок вызовов.

  **Авто-ЧСС и D/S-маркеры.** В файлах без `WaveformSequence` детектор ЭКГ, запечённой в пикселях, отбрасывал трассу дважды: порог «шире 50% кадра» (на реальном файле — 49.5%) и зелёный текст аннотации («4CC : 275») в медиане по колонкам, порождавший фантомные пики. Детектор выбирает компонент связности самой трассы и привязывается к её размаху; воркеры идут waveform → burned → optical flow, кнопка D/S не молчит при неудаче. На файле из заявки: 16 маркеров (8 циклов, conf 0.371) и ЧСС 101.7 bpm вместо двух отказов.

  **«В правой панели».** Режим скрывал строку инструментов и не крепил её никуда; существующий `ToolButtonRow` теперь монтируется в верх правой панели и сворачивается в «Ещё» по её ширине. Переключения row↔panel и запрет строки в Multiview согласованы, hint обновлён (RU/EN).

  **Лист отчёта.** Debounced-рефреш перезагружает `QPdfDocument`, а `QPdfView` после перезагрузки сбрасывал скролл к первой странице — страница уезжала из-под карточки «откуда значение». Позиция чтения запоминается и восстанавливается с клампом под новый документ; закрыт teardown-краш `pageCount`.

  **Диалог FPS.** Двойной щелчок по «FPS» в транспорте открывает диалог установки FPS текущего клипа: значение хранится на сессию по SOP Instance UID и пере-таймингует клип без сброса плейхолдера и контуров, плеер/фазовая линейка/авто-ЧСС берут новый таймбейз из состояния; для MP4 явный ввод важнее измеренного.

  **Меню.** Qt рисует иконку пункта меню у самой рамки, игнорируя padding элемента — «Загрузить с сервера…» шла вплотную к краю. `QMenu` получил горизонтальный padding 8 px, у элемента 24 → 20 px (текст сдвинулся на 3 px). Кнопки, `QTreeWidget` и список секций настроек проверены отдельно; generic-правило для `QListWidget` сознательно не добавлялось — сузило бы ячейки `ThumbnailGallery`. Golden-фикстуры QSS и sha256-пины перегенерированы.
