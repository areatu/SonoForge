- `feat(catalog)`: TP-0 PR-3 — сверка каталога измерений с ASE 2025 Table 6 «Measurement dictionary» (спека TP §5.2, A-12; **видимых изменений нет**). Новый доменный модуль `domain/ase_table6.py`: 117 строк таблицы (название, сокращение, единица, рекомендуемое число знаков) в нотации каталога, плюс списки явных отклонений (`ASE_UNIT_DEVIATIONS`, `EN_LABEL_EXCEPTIONS`) и строк таблицы, которых в приложении нет (`TABLE6_NOT_IN_CATALOG` — с причиной). 69 измерений каталога ссылаются на строку таблицы (`MeasurementSpec.ase_row`), остальные — на профильные документы ASE (2025 диастолическая функция, 2025 правые отделы, 2017 стеноз АК / митральный стеноз / аортальная регургитация, 2017 митральная и трикуспидальная регургитация, 2015 камеры). Каждая строка таблицы либо используется каталогом, либо перечислена как «вне панели» — «забытой» строки быть не может.
