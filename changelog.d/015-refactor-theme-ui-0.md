- `refactor(theme)`: токены оформления вместо сырых цветов (UI-0 PR-1, спека редизайна §5, UD-09). Новый пакет `presentation/theme/`: `tokens.py` (словарь ролей: `surface.*`, `line.*`, `text.*`, `accent.*`, `state.*`, `focus.*`, `progress.*`, `slider.*`, `paper.*`, `overlay.*`; таблица соответствия прежним 28 ключам; сетка размеров 4 px, радиусы 4/6/8/10, высота контролов 28/32, иконки 16/18, шрифты 11.5/12.5/13.5/15/24), `palettes.py` (единственное место с hex-литералами), `qss.py` (таблица стилей собирается из токенов, результат кэшируется по паре «тема, размер шрифта»), `contrast.py` (правила WCAG 2.1 AA и список проверяемых пар — их использует и CI-скрипт), `system_theme.py` (определение схемы ОС). Прежнее имя `presentation/theme_tokens.py` (плоский модуль токенов) остаётся фасадом: он переэкспортирует пакет и уходит вместе с прежней палитрой в UI-8. `presentation/dark_theme.py` остался фасадом: `get_theme_palette()` по-прежнему отдаёт прежние 28 ключей, но теперь они *вычисляются* из токенов; `build_clinical_stylesheet()` отдаёт ту же строку. **Вид не изменился:** таблицы стилей прежних тем (navy, светлая, VS Code dark, VS Code light) закреплены golden-файлами `tests/fixtures/ui/stylesheet_*.golden.txt` и совпадают с предыдущим выпуском побайтно (проверено и по QSS, и по палитрам — `tests/fixtures/ui/legacy_palettes.json`); тест `tests/unit/test_theme_tokens.py` (27) сравнивает их с golden-файлами, поэтому случайная смена оттенка в палитре валит сборку. Тема «Графит» описана в токенах (значения спеки §5.2: surface.0 #0b0d0f … accent #2bd1cb) и проверена контрастом, но в списке тем пока не выбирается — это UI-0 PR-2. Группа `overlay.*` объявлена, значения придут в UI-0 PR-7 (перенос вьюера на токены без изменения цветов). Перенос остальных областей на токены — UI-0 PR-3…PR-6, удаление прежней палитры — UI-8.
