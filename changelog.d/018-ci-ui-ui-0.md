- `ci(ui)`: храповик цветовых литералов и проверка контраста токенов (UI-0 PR-1, спека редизайна §5.3, G-3/G-4). `scripts/check_ui_colors.py` считает hex-литералы в `presentation/`, `ui/` и `constructor/` вне модуля палитр и сравнивает с базой `scripts/ui_colors_baseline.json` (снимок — 378 литералов): рост — ошибка сборки, снижение — база обновляется (`--update`), подъём базы требует `--allow-growth` и обоснования в PR. Считаются только строковые литералы: цвет в комментарии (например, ссылка на задачу `#150`) цветом не считается, а файл, который не удаётся разобрать, сканируется как обычный текст. Регулярка ловит и ложные срабатывания: `#added` (имя объекта QSS) и `&#123;` (HTML-сущность) литералами не считаются. `scripts/check_contrast.py` проверяет пары токенов по WCAG 2.1 AA: для темы «Графит» — ошибка (все 26 пар проходят), для прежних тем — только отчёт (33 пары ниже минимума, цвета без согласования не меняются; `--strict` делает и их ошибкой). Оба скрипта читают пакет токенов, в котором нет импорта Qt, и работают на стандартной библиотеке.
