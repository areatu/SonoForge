- `fix(simpson)`: #548 — камерный Simpson для ЛП/ПП/ПЖ больше не выдаёт среднее двух моноплановых объёмов за биплановый. `calculate_chamber` при двух проекциях теперь ставит метод `simpson_mean_monoplan`, а не `simpson_biplan`; среднее осталось описательным `mean_es_volume_ml`, тогда как прежнее публичное имя `biplane_es_volume_ml` удалено. Новый гейт `confirmed_biplane_es_volume_ml(result)` возвращает объём только при `method == "simpson_biplan"`, `biplane_verified`, конечном положительном значении и требуемой фазе. Поэтому `la.lav_bp`, `la.lavi_bp`, `lav_bi_index_ml_m2` и строка «Биплан» появляются только у настоящего подтверждённого biplane (сейчас — LV), а не у среднего.
  Legacy-записи без флага загружаются без миграции и без ошибки: `ChamberSimpsonResult.biplane_verified` по умолчанию `False`, `biplane_es_ml` по умолчанию `None`, поэтому старый `simpson_biplan`, сохранённый до версии 4.1, не индексируется и не классифицируется по биплановым порогам. `body_surface`, status bar, overlay, индексный formatter, `report_builder`, `report_conclusion`, `study_projection`, калькулятор диастолы и `resolve_study_inputs` переведены на гейт; при двух монопланах `la.lavi` берётся из `lav_4c` (или area-length), а не из среднего. В статус-баре, отчёте и PDF отсутствуют биплановые строки для ЛП.
  Проверка: `ruff check`/`ruff format --check` по `src`/`tests` — чисто; `mypy` — 399 файлов без ошибок; ratchet-скрипты пройдены. Добавлены регрессии: среднее ≠ biplane, legacy-флаг → `None`, положительный подтверждённый biplane, fallback `la.lavi` на 4C, отсутствие `la.lav_bp` при двух проекциях, запрет биплановой строки в overlay/отчёте/PDF и индексном overlay. Это защитный PR 4.1: настоящий сопряжённый биплановый расчёт для согласованных проекций/фаз (4.2) не входит; клиническая валидация и нативная GUI-приёмка не проводились.
