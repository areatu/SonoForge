- `feat(lv_strain_layers)`: #646 (план А.8) — послойный стрейн ЛЖ (эндо/средний/эпи): кривые и GLS по каждому слою на одном материальном определении, селектор слоя в панели окна strain, трансмуральный градиент в отчёте; синтетический gold-тест на известный слоевой градиент.
  - Зачем: эндокард деформирует больше эпикарда — трансмуральный градиент падает при субэндокардиальной ишемии раньше, чем ФВ; без послойного измерения это свойство недоступно (issue #646, спека — тело issue).
  - Как: кольца ядер между эндо- и эпикардиальными контурами уже семплируются зоной (`sample_kernels_in_zone`, 3 кольца) и трекаются — нового трекинга нет; каждый слой — своя материальная линия, кривая слоя считается **той же** функцией взвешенной продольной деформации, что и репортимая глобальная (`compute_weighted_longitudinal_strain_gl`), на дуговых колонках слоя с теми же NCC-весами. Эндокардиальный слой побитово совпадает с глобальной кривой (один тест закрепляет); mid/epi — то же измерение на своей линии. Правило видимости слоя — как у глобальной кривой (fallback на полную дугу при <8 видимых узлах); при откате эндо-дуги радиальным fallback'ом слои считаются без фильтра видимости — то же измерение, что и репортимая кривая.
  - Модель: `StrainResult.layer_curves / layer_gls / layer_segment_curves`; `StrainAnalysis.layer_gls / transmural_gradient_pp` (+ определение слоёв в записи); `StrainReport.layer_gls_by_view / layer_mid_pct / layer_epi_pct / layer_gradient_pp` (средние по видам, давшим значение) + строки протокола в группе ЛЖ («ГлПродДеф среднего слоя», «ГлПродДеф эпикарда», «Трансмуральный градиент (эндо−эпи)», пп — положительный, когда эндокард деформирует больше). Кодек: поля слоёв пишутся в документ только когда слой измерен — форма записи без слоёв не меняется.
  - UI: группа «Слой миокарда» в панели окна strain (эндокард по умолчанию, сигнал `strain_layer_changed`); режим «Кривые» строит посегментные кривые выбранного слоя, заголовок показывает GLS слоя, отсутствие кривых у слоя — честная пометка «нет кривых → эндокард» вместо подмены; сводка — строки среднего слоя, эпикарда и градиента («--», пока слой не измерен); CSV-экспорт — блок «GLS layers (endo/mid/epi)» и градиент с определением.
  - Честные границы: послойные кривые — глобальные (пиковые) значения слоёв, не per-segment bullseye-карта слоёв; толщина стенки берётся из существующей зоны (эпи-контур = расширение эндо на толщину, пока нет прямой эпи-сегментации) — градиент зависит от качества зоны, и определение слоёв это декларирует в записи.
