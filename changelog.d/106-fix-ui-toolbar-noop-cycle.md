- `fix(ui)`: полоса инструментов больше не перерисовывается при неизменном наборе кнопок, и разорван круг импортов между сборщиком отчёта и форматами (CI зелёный). Три причины, которые ловили гейты партии S1–S5. (1) П.5 научил `ToolButtonsBase.set_specs` беречь собранные контролы — но условием была «те же id», поэтому любой повторный запрос гейтов (смена пресета компоновки, применение настроек, смена клипа) вызывал `refresh()` всей полосы: тест `test_layout_v2_window.py::test_preset_switch_does_not_refresh_unchanged_toolbar` видел три перерисовки там, где их не должно быть вовсе. Теперь список сравнивается по значению: равный список не делает ничего (ни пересборки, ни перерисовки — нажатая/наведённая кнопка и отполированные иконки остаются нетронутыми), те же id с изменившейся ячейкой (разделитель, гейт, подпись) перерисовывают полосу на месте, и только другой набор id пересобирает её. Новый тест `test_heart_rate_tools_gate.py::test_the_strip_touches_its_controls_only_when_the_gate_list_changed` фиксирует все три ветки, в том числе что контрол переживает перерисовку. (2) `report_builder` спрашивал формат у `report_profiles` (ленивый импорт в `build_report_document`, чтобы лист фильтровался один раз для превью, PDF, CSV и JSON), а `report_profiles` брал у сборщика id групп и `ReportGroup` — круг из двух модулей, который запрещает страж графа импортов (#328): «ленивый импорт прячет круг от интерпретатора, а не от архитектуры». Id групп и их порядок печати вынесены в новый листовой модуль `domain/services/report_groups.py`, который не импортирует ничего из слоя отчёта; сборщик явно реэкспортирует их (`as`-форма), поэтому все потребители — `report_sections`, палитра команд, галерея, тесты — читают их там же, где читали. Формату от сборщика нужен только id группы, и он описан протоколом `PrintedGroup` (read-only `key`, чтобы замороженный dataclass ему удовлетворял) с `TypeVar`, поэтому `profile.groups(...)` по-прежнему возвращает `tuple[ReportGroup, ...]` и mypy в strict не жалуется. (3) Два ретчета разошлись с деревом: `scripts/function_length_baseline.json` (п.12 вынес `_read_str` — `load_user_preferences` 208 строк ушёл из списка длинных функций, `_build_pages` 356 → 328 после выноса `_build_report_page`; ни одна функция не выросла) и `scripts/id_references_baseline.json` (total 676 не изменился, но одна ссылка переехала из комментария в докстринг: comments 218 → 217, strings 458 → 459). Тесты: партиция `not gui and not interactive` целиком зелёная, `test_layout_v2_window` + `test_heart_rate_tools_gate` + `test_ds_markers_button` (43) зелёные, `test_architecture_boundaries` + `test_function_length_ratchet` + `test_id_references_ratchet` (77) зелёные, mypy strict — 267 файлов без замечаний.
