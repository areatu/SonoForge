- `feat(doppler)`: #559 — принятые и исключённые повторы Doppler с явным выбором циклов, n, mean, SD и CV.

**Что добавлено**

- У каждого повторного пика, интервала и трассы появился `accepted` (по умолчанию `true`). Исключённый цикл остаётся в документе и виден на спектре пунктиром, но не входит в среднее, SD, CV и ЧСС по RR. Поле пишется только при `false`, поэтому wire-формат всех принятых и старых документов не меняется; схема v6 допускает optional `accepted`.
- `repeat_statistics` — единственный расчёт принятых/исключённых/выбранных значений и выборочного SD (`n−1`), CV = SD/|mean|·100. `doppler_metrics` берёт среднее последних трёх **принятых**; всё остальное (Vmean, PGmean, Vmax из трасс, ЧСС) идёт через те же фильтры.
- Отчёт: для Vmax/VTI `n` — число принятых значений в окне, к значению добавлены `SD` и `CV`; числовое `value` не меняется.
- Диалог **«Повторы Допплера…»** (меню приложения и `Ctrl+K`): список повторов по параметрам, галочка «Принят», живая сводка «принято/исключено · n · среднее · SD · CV». Исключённая строка приглушена; «Применить» отправляет тот же DTO в viewer и сессию измерений.
- Справка RU/EN: раздел 9.2 описывает выбор циклов при AF и явно говорит, что автоматического правила для AF нет.

**Почему без автоопределения AF**

Аудит #559 требует отсутствия скрытого универсального правила. Приложение не угадывает фибрилляцию предсердий и не выбирает циклы за оператора: метод — среднее последних трёх принятых, исключения делает пользователь.
