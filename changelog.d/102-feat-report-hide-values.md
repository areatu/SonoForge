- `feat(report)`: скрытие отдельного показателя в отчёте с возможностью вернуть (п.9 плана `docs/reviews/2026-11-06-ui-batch-14-items-plan-ru.md`). Врачу нужно убрать из протокола одну строку, не удаляя само измерение; нарисовать «галочку» поверх листа нельзя — лист это точные байты PDF (S-11), и любые пометки внутри него разошлись бы с экспортом. Поэтому строка адресуется **стабильным ключом**: `ReportValue.key` формы `group:label:ordinal` проставляется в `build_report_groups` (`_keyed_values`), и порядковый номер считается по всей группе до скрытия, так что восстановление строки никогда не перенумеровывает остальные. Новый фильтр `without_values(document, hidden_keys)` в `report_builder` применяется один раз в `build_report_document(..., hidden_keys=)`: превью, PDF, CSV и JSON теряют одни и те же строки, а группа, оставшаяся без значений, исчезает вместе со сносками; неизвестный ключ ничего не меняет — перезагрузка исследования не воскрешает строку. UI: левый клик по ячейке значения открывает меню «Скрыть в отчёте» (`ReportPreview._handle_value_press`/`_build_value_menu`, сигнал `value_visibility_changed(key, hidden)`), в левой колонке режима появился блок «Скрытые: N» с кнопкой «вернуть» на строку (`ReportSectionsPanel.set_hidden_values`, `restore_value_requested`, стилизация `reportHiddenRow`) — оба пути обратимы. Набор скрытых ключей живёт во вкладке (`TabSession.report_hidden_values`) и очищается вместе с заключением при новом источнике; завершённый отчёт не даёт ни скрыть, ни вернуть, поскольку байты заморожены. Тесты: новый `tests/unit/test_report_hidden_values.py` (9 — стабильные ключи, независимость от позиции, удаление и восстановление строки, игнор неизвестного ключа, исчезновение пустой группы, сохранение сносок, `without_values` без изменений возвращает тот же объект, разные ключи для одинаковых подписей, совпадение PDF/CSV/JSON), `tests/unit/test_report_preview.py::TestHideValueMenu` (4 — клик по ячейке просит скрыть, клик мимо не наш, завершённый лист меню не даёт, строка без ключа скрыта быть не может), `tests/unit/test_report_sections_panel.py::TestHiddenValuesList` (4 — пусто без скрытых, счётчик и кнопки, вернуть сообщает ключ, на замороженном листе кнопка неактивна), `tests/unit/test_presentation_main_window.py::TestHiddenReportValues` (5 — скрытие доходит до документа и вкладки, возврат восстанавливает, левая колонка показывает скрытое, завершённый отчёт отказывает, экспорт берёт тот же документ). Прогоны: report-наборы + превью + секции + окно — 353 зелёных.
