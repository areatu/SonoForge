# fix(ci): восстановление Presenter-пинов и проверка сайта

- Drift healer теперь добавляет отслеживаемый файл `build/presenter/pinned-packages.txt` с `git add -f`: каталог `build/` игнорируется, из-за чего обычный `git add` завершался ошибкой и блокировал исправление PR зависимостей.
- Проверка цитирования ищет версию в помесячном changelog и не требует, чтобы DOI отдельной версии указывал на текущий релиз. Общий DOI проверяется отдельно. Изменения цитирования и истории запускают сборку сайта; проверки сайта также запускаются в CI PR.
- Добавлен stdlib-тест реального шага healer: проверяет коммит исправления в игнорируемом каталоге и повторный запуск без изменений.

Проверки: `python -m unittest discover -s .github/tests -v`, `python -m unittest discover -s site/tests -v`, `python tools/release/presenter_pins.py`.
