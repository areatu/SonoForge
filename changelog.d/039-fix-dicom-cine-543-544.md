- `fix(dicom)`: #543/#544 — reader и DICOM-сессия используют общую идентичность файла (canonical path, size, mtime/ctime и file ID); замена файла инвалидирует пиксели, изменение во время чтения вызывает ограниченный retry/явный отказ. Общий pixel cache хранит immutable bytes-backed массивы: для редактирования нужен `copy()`. Sparse projection несёт исходные индексы и не попадает в full-cine memo; `require_full_cine` проверяет все индексы до возврата стека, смена источника/числа кадров сбрасывает старый cine.
  Регрессионные тесты покрывают in-place/atomic replacement, алиасы путей, удаление/замену при decode, неизменяемость кеша, sparse gaps, дозагрузку, eviction и смену источника. Политика resident-memory/backing-buffer budgets (#545) не изменялась. File identity — stat-based generation, не криптографический хеш и не атомарный snapshot файловой системы.
