- `fix(ci)`: устаревший перезапуск больше не отменяет проверки нового коммита, а capacity healer повторяет зависимые задания одной операцией.

  CI и сборка группируют PR и ручной запуск по имени ветки и SHA её головы. Прежний групповой ключ позволял запоздавшему автоматическому rerun старого запуска вытеснить текущий CI; именно так был отменён запуск `41865208078` и итоговые проверки стали красными без падения тестов. Изоляция по SHA сохраняет отмену дублей одного коммита; задержанный rerun более старого коммита не отменит новый.

  Capacity healer не перезапускает чужие ветки, устаревшие SHA, более старый запуск workflow на той же ветке, уже перезапущенную попытку и выполняющийся run. При реальной нехватке раннеров выполняется один rerun всех неуспешных заданий с зависимыми проверками вместо нескольких конкурирующих запросов для отдельных заданий. Проверки доступа выполняются до запроса rerun; ошибки проверки не дают перезапустить run. Локальные stdlib-тесты выполняют настоящий shell-шаг с поддельным GitHub API и проверяют актуальные, устаревшие и ошибочные случаи.
