- `fix(theme)`: инверсия темы «Как в системе» на Windows (UI-0 PR-1, спека редизайна §2.1, UA-16). `_resolve_theme("system")` возвращал *светлую* палитру при `AppsUseLightTheme == 0`, то есть при тёмной теме системы (соседняя `_is_system_dark()` считала правильно) — пользователь с тёмной Windows получал светлый интерфейс. Теперь схему ОС определяет один источник (`presentation/theme/system_theme.py`): Windows читает `AppsUseLightTheme` (`0` — тёмная), macOS спрашивает `defaults` о стиле интерфейса, прочие системы сохраняют тёмную тему приложения, как раньше. Палитра и логотип следуют одному ответу: раньше на Linux в режиме «Как в системе» ставился светлый логотип на тёмную панель, а на macOS при недоступном `defaults` палитра была тёмной, а логотип — светлым. Тесты: `tests/unit/test_theme_system_theme.py` (12, мок `winreg`: тёмная система → «dark», светлая → «light», недоступный реестр → «dark», macOS, Linux) и регрессия фасада в `tests/unit/test_presentation_dark_theme.py` (5 GUI-тестов, мок реестра: тёмная и светлая система, недоступный реестр, согласие палитры с логотипом, таблица стилей по каждому вызову).
