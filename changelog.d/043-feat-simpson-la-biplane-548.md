- `feat(simpson)`: #548 — настоящий биплановый объём ЛП методом сопряжённых дисков. A4C и A2C одной фазы дают `simpson_biplan`: диаметры соответствующих дисков перемножаются, высота диска равна `max(L_A4C, L_A2C) / 20`. Для эллипса 40×100 мм в A4C и 20×100 мм в A2C истинный biplane равен **41.90 mL**, тогда как среднее двух монопланов — **52.38 mL** (различие 20%); тест закрепляет аналитическую формулу, а не результат старой пробы. Формула вынесена в публичный `biplane_volume_ml` и используется и для ЛЖ, и для ЛП.
  Биплановый результат требует обе открытые дуги с митральным кольцом **в одной фазе**; отсутствие вида, фазы или кольца не даёт бипланового значения, а ES одной проекции не сочетается с ED другой. `biplane_es_ml` заполняется только этим расчётом и вместе с `method="simpson_biplan"` проходит гейт `confirmed_biplane_es_volume_ml`; поэтому `la.lav_bp`, `la.lavi_bp`, `lav_bi_index_ml_m2`, «LAV Bi» в статус-баре, отчёт, PDF, заключение и диастолический индекс снова доступны — но только для подтверждённого настоящего biplane.
  Клиническая граница: биплановый метод включён только для ЛП, где 2D biplane disk summation валидирован. ПП остаётся однопроекционным; для ПП/ПЖ две проекции по-прежнему дают описательное `simpson_mean_monoplan` без бипланового индекса. Формула не выдаётся за валидированную 2D-оценку EF ПЖ. Сохранённые результаты 4.1 без `biplane_verified` остаются недоверенными; method ID стабилен, миграции нет.
  Проверка: `ruff check`/`format` — чисто; `mypy` — 399 файлов без ошибок; ratchet-скрипты пройдены. Добавлены тесты аналитического эллипса, несовпадения фаз, одиночной проекции, запрета biplane для RA/RV, положительного статус-бара, индексации из реального расчёта и прежние гейты неизвестного метода/легаси.
