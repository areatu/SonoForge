- `fix(dicom)`: #551 — reader принимает валидный dataset без Part 10-преамбулы, не ослабляя проверку произвольных файлов. `validate_dicom_header` сохраняет быстрый путь по `DICM` на offset 128 и добавляет ограниченный fallback: заголовок читается `stop_before_pixels` с `defer_size`, затем требуются валидные SOP Class/Instance и Study/Series UID. Битый или обрезанный raw-заголовок и произвольный бинарный файл дают `CorruptDicomError`; big-endian raw dataset — `UnsupportedDicomError`.
  `DicomSession` определяет кодировку raw dataset (implicit/explicit little-endian) и сканирует PixelData с offset 0, поэтому много­кадровый raw-клип декодируется, а не только открывается metadata. Scanner больше не добавляет в галерею DICOMDIR (индекс) и SR/PR/encapsulated documents: неподдерживаемые типы пропускаются без записи в error log, а отсутствие image identity/geometry остаётся повреждением. Reader для не-изображения выдаёт `UnsupportedDicomError`, а не ошибку декодирования кадра. `measurement_sources` проверяет заголовок тем же валидатором и читает raw header с `force=True`.
  Проверка: новый `tests/unit/test_zz_dicom_raw_dataset.py` (22 теста, explicit/implicit LE, декодирование кадра, offset 0, DICOMDIR/SR/PR, битые/произвольные/обрезанные/big-endian данные, scanner без ложного corruption). Прогоны DICOM/Orthanc-набора — 950+ passed; `ruff`, `mypy` и архитектурные тесты чисто. Документация: раздел 5.1 в `TECHNICAL_HELP_RU/EN`.
