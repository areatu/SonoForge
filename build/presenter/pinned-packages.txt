# SonoForge Presenter — pinned build/runtime dependency set (lite profile).
#
# Same packages as the full pyproject.toml MINUS:
#   onnxruntime  (AI segmentation — not in Presenter)
#   pymupdf      (reference PDF rendering — not in Presenter)
#   openpyxl     (reference constructor Excel import — not in Presenter)
# and with PySide6-Essentials instead of the full PySide6 metapackage
# (skips PySide6-Addons → no QtWebEngine, ~175 MB wheel saved).
#
# EVERY version below comes from uv.lock, including transitive dependencies, so
# the lite build has no floating resolution of its own. The list is generated:
#
#   python tools/release/presenter_pins.py --write   # after a uv.lock change
#   python tools/release/presenter_pins.py           # check (CI and the build jobs)
#
# The check (QH-5a) fails when a pin drifts from the lock, when a package of the
# Presenter dependency closure is missing, or when an excluded package
# (onnxruntime, PyMuPDF, openpyxl, the PySide6 addons metapackage) sneaks in.
# Versions are resolved for the Presenter build environment (CPython 3.11,
# Linux x86_64 / Windows x64).
#
# A few entries only matter on one platform (colorama and pywin32-ctypes on
# Windows, jeepney and secretstorage on Linux). They are pinned anyway so both
# builds share one file; each is a pure-Python wheel that installs inert on the
# other platform and is not bundled into the artifact.
#
# NOTE ON THE FILE NAME: this is deliberately NOT named requirements*.txt.
# GitHub's dependency graph parses any requirements-style manifest and the
# Dependency Review gate (deny-licenses: GPL-3.0) would treat every entry
# of a newly added manifest as an "added" dependency — even though this
# list is a strict SUBSET of pyproject.toml/uv.lock already tracked in the
# graph (the project itself is GPL-3.0; pylibjpeg-libjpeg ships in the
# main product too). The rename avoids that false positive without
# weakening the repository license policy.
#
# Usage (build machine):
#   uv venv .venv
#   uv pip install --python .venv -r build/presenter/pinned-packages.txt
#   uv pip install --python .venv "pyinstaller==$(python .github/scripts/locked_version.py pyinstaller)"
#   python -m PyInstaller build/presenter/sonoforge-presenter.spec --noconfirm --clean
