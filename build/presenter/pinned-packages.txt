# SonoForge Presenter — pinned build/runtime dependency set (lite profile).
#
# Same packages as the full pyproject.toml MINUS:
#   onnxruntime  (AI segmentation — not in Presenter)
#   pymupdf      (reference PDF rendering — not in Presenter)
#   openpyxl     (reference constructor Excel import — not in Presenter)
# and with PySide6-Essentials instead of the full PySide6 metapackage
# (skips PySide6-Addons → no QtWebEngine, ~175 MB wheel saved).
#
# Versions are PINNED to the exact resolutions in uv.lock so the Presenter
# build is reproducible and uses the same tested dependency set as the
# main product. When uv.lock is refreshed, update these pins deliberately
# (script: see build/presenter/README.md).
#
# NOTE ON THE FILE NAME: this is deliberately NOT named requirements*.txt.
# GitHub's dependency graph parses any requirements-style manifest and the
# Dependency Review gate (deny-licenses: GPL-3.0) would treat every entry
# of a newly added manifest as an "added" dependency — even though this
# list is a strict SUBSET of pyproject.toml/uv.lock already tracked in the
# graph (the project itself is GPL-3.0; pylibjpeg-libjpeg ships in the
# main product too). The rename avoids that false positive without
# weakening the repository license policy.
#
# Usage (build machine):
#   pip install -r build/presenter/pinned-packages.txt pyinstaller
#   python -m PyInstaller build/presenter/sonoforge-presenter.spec --noconfirm --clean
