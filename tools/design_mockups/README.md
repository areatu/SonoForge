# Макеты интерфейса (dev-only)

Скрипты рисуют PNG-макеты интерфейса SonoForge. В приложение не входят.

## Раунд 1 — варианты главного окна

Результат: `docs/images/main-window-variants/`.

- `kit.py` — примитивы QPainter, иконки, кадры эхо из `tests/fixtures/for_pero`
  (обезличенные), синтетические спектры Допплера и М-режим.
- `common.py` — данные вымышленного исследования, общие виджеты.
- `screen_a.py` … `screen_e.py` — варианты A–D, обвязка окна по ОС, обзорный лист.
- `render_all.py` — запуск раунда 1.

## Раунд 2 — вариации компоновки

Результат: `docs/images/layout-variants/`. Основа зафиксирована (A1/A2, графитовая
палитра, заголовок окна Windows 11); меняется только расположение панелей и кнопок.

- `lay_common.py` — общие блоки: строка пациента, клипы (сетка и лента),
  панели инструментов, командная строка, полоса шага, панель протоколов.
- `lay_main.py` — M1 «Зеркальная», M2 «Лента снизу», M3 «Командная строка».
- `lay_focus.py` — F1/F2, режим «Фокус» для одиночного файла.
- `lay_report.py` — R1/R2/R3, отчёт: вкладка справа, рядом со снимком, отдельный режим.
- `lay_ref.py` — S1/S2, справочник: отдельное окно и карточка в контексте
  (нормы и рисунок берутся из `resources/references/`).
- `lay_settings.py` — O1, настройки «Внешний вид и компоновка».
- `lay_sheet.py` — K1 «где ставить кнопки» (из фрагментов других макетов) и обзорный лист.
- `lay_run.py` — запуск раундов 2 и 3. K1 и O1 используют готовые PNG, поэтому идут
  после остальных макетов (O1 берёт фон из A1 раунда 1).

## Раунд 3 — утверждённый вид

Результат: `docs/images/ui-redesign/`, иллюстрации к спеке
`docs/superpowers/specs/2026-10-16-ui-redesign-spec-plan-ru.md`.

- `lay_final.py` — выбор пользователя после раунда 2: компоновки «Классическая» (A1),
  «Зеркальная» (M1), «Лента снизу» (M2) и «Кнопки в правой панели» (как сейчас);
  полоса шага под снимком; отчёт R3 с переключателем «Изображения | Отчёт»;
  карточка справочника без рисунка; настройки компоновки. Запускается из
  `lay_run.py`; экран настроек берёт фон из `01-main-classic.png`, поэтому идёт последним.

`icons/` — Lucide (ISC) и Phosphor (MIT), лицензии рядом.

## Запуск

Нужны PySide6 ≥ 6.7, numpy и Pillow.

```bash
QT_QPA_PLATFORM=offscreen python render_all.py            # раунд 1, все макеты
QT_QPA_PLATFORM=offscreen python render_all.py render_c1  # один макет
QT_QPA_PLATFORM=offscreen python lay_run.py               # раунды 2 и 3, все макеты
QT_QPA_PLATFORM=offscreen python lay_run.py lay_report    # один модуль
QT_QPA_PLATFORM=offscreen python lay_run.py lay_final     # только раунд 3
```

Каждый макет рисуется в отдельном процессе: в PySide6 6.12 на CPython 3.11 после
очень большого числа вызовов QPainter возникает ошибка `none_dealloc`.

## Раунды быстрого доступа к инструментам

- `quick_access.py` + `quick_access_run.py` — раунд 1 (2026-10-27): подписанный
  ряд, закреплённая рейка, доска анатомии →
  `docs/images/quick-access-concepts/`.
- `quick_access_v2.py` + `quick_access_v2_run.py` — раунд 2 (2026-10-30):
  активный инструмент с параметрами, две полосы, инструменты в полосе шага →
  `docs/images/quick-access-concepts-v2/`. Отличие от раунда 1: меняется модель
  ряда (свёртка, дубли, модификаторы, параметры инструмента), а не место панели.
  Ширины ячеек в макетах считаются по реальным подписям, поэтому ни один вариант
  не обрезает текст — это то же правило, что теперь действует в самом ряду
  (`presentation/tool_buttons/row.py`).
