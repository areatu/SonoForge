# Vendor reference values (Samsung RS85, Philips EPIQ) — для сверки STE

Источник: экраны STE самих аппаратов из `data/dicom/For_pero` (`strain_sams*.dcm`,
`strain_ph*.dcm`). Это **не** перепечатка литературы, а числа того же пациента, что и
клипы `gold*.dcm`, поэтому по ним можно сверять определения, а не только «примерно
так бывает».

**Пациенты не идентифицируются**: ниже только дата исследования и аппарат. В кадрах
клипов есть впаянные в изображение ФИО — сами клипы и производные фикстуры
(`tests/fixtures/for_pero/*.npz`) из репозитория публиковать нельзя.

## Что из этого следует для нашего модуля

1. **Итоговое число вендора — арифметическое среднее трёх видов** (Samsung: «ГлобПродДеф
   −17.8 %» при −19.0/−20.0/−14.5; Philips: «GLS_ЭНДО_ПИК_ср. −22.5 %» при
   −18.0/−25.0/−24.3). Наш `GLS_AV` считается так же — по валидным видам.
2. **Отчётное число — пик** («ГлобПродДеф», «GLS_ЭНДО_ПИК»), а не значение в AVC.
   У нас основное число — тоже пик глобальной кривой, ESS идёт рядом.
3. **Разброс по видам у вендоров 1.4–8.6 п.п.** (в среднем ~5). Это практический
   ориентир для нашего межвидового контроля: строже ~5 п.п. ругать нормальный клип нельзя.
4. **AVC у Samsung выводится в мс** (224/281/318) и растёт с ЧСС-независимо от неё, то
   есть это измеренная точка, а не доля RR. Нам для сверки нужен наш `avc_source` и
   `avc_index`, а не «пик = AVC».
5. **Диапазон клипов:** от −8 % (ФВ 30 %) до −22.5 % — то есть в наборе есть и нормы, и
   тяжёлая дисфункция; проверять модуль надо на обоих концах.

## Чего в этой таблице нет и что нужно, чтобы сверка была честной

* **Контуров** (gold) для этих клипов: в `gold/` лежит разметка только одного
  исследования (`gold105.dcm`). Без нарисованного ЭД-контура мы не можем посчитать
  свой GLS на том же клипе — сравнение с вендором будет «по числам», а не «на одних
  кадрах».
* **Нативных ЭКГ-тегов**: во всех 19 клипах `WaveformSequence` отсутствует, ЭКГ
  впаяна в изображение (видна на кадрах `*+ECG*`, `gold_Ph_ECG2`). Для автодетекции
  KД/КС по ЭКГ это означает работу с изображением, а не с тегами — отдельная задача.
