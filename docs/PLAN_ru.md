# План работ SonoForge (расширенный состав, без хронологии)

> Статус: **scope-план**, не спецификация. Хронология и спека — отдельно, позже.
> База: стратегический анализ `docs/STRATEGY_ANALYSIS_ru.md` + обратная связь владельца.
> Исключены из текущего охвата (отложено): контраст LVO/MCE, CEUS-TIC, RV 3D-квантификация,
> TEE-многоплоскостность, 3D/4D импорт, MPR/VR для CTMR, PET/CT+fusion, радиологические ROI-инструменты,
> авто-кодирование ICD-10/CPT.
> Уже частично реализованы (допилить): **33** таймлайн ED/ES, **34** guided-экзамены ASE.

---

## А. Ядро эхокардиографии (1–14)

1. **Auto View Recognition** — классификатор вида клипа (A4C/A2C/PLAX/SAX/A3C/PSAX) по первому/опорным
   кадрам; подставляет `StudyProfile` и фильтрует панель. База для автоматизации workflow.
2. **One-click Auto-EF** — композиция view-rec + LV-сегментации + temporal fusion + biplane Simpson;
   выдаёт EDV/ESV/EF с ручной правкой. Прямой аналог Easy AutoEF.
3. **ЭКГ-независимая фазовая сегментация** — learned cardiac phase field φ(t)∈[0,1), обученный
   самоконтролем по периодичности неразмеченных клипов (без ЭКГ и без разметки). Первичный гейтинг.
4. **Image-based гейтинг как первичный путь** — гибрид: ЭКГ, если теги присутствуют, иначе кадр;
   единый источник ED/ES/ЧСС для STE, strain, диастологии, MW.
5. **Авто-обрезка вшитой полосы ЭКГ из ROI** — детект фиксированной нижней полосы (Samsung RS85 и др.)
   и исключение её из трекинга/оптического потока.
6. **Strain ЛП (LA strain)** — трекинг ЛП поверх A4C/A2C с фазовой привязкой; reservoir/conduit/booster.
7. **Strain ПЖ (RV strain)** — трекинг ПЖ на RV-focused видах; GLS ПЖ, интеграция в bull's eye/кривые.
8. **Послойный стрэйн (endo/mid/epi)** — довести многослойные маски/трекеры и отчётность по слоям.
9. **Myocardial Work без ЭКГ** — pressure-strain петли из strain + манжетного АД + image-derived тайминга
   клапанов (MVc/AVo/AVc/MVo); GWI/GCW/GWW/GWE. Разблокируется пунктами 3–4.
10. **Диастология «под ключ»** — авто-извлечение E/A, e', E/e', TR, PV, IVRT в единый блок с
    авто-градацией и честной обработкой «indeterminate».
11. **Стресс-Эхо** — 17-сегментный WMSI (rest/stress), авто-сравнение визитов, добутаминовые протоколы,
    опционально контрастная перфузия (качественно).
12. **Педиатрия/Z-score + фетальное Эхо + growth charts** — педиатрическая база норм, BSA-индексированные
    Z-score, фетальные биометрия/кардио.
13. **Акушерство** — HC/AC/FL/BPD, EFW (Hadlock), допплер артерии пуповины, околоплодные воды.
14. **Эластография SWE** — shear-wave velocity/stiffness + качественная шкала для щитовидной/печени.

## Б. DICOM / радиологические возможности (15–19)

15. **DICOM SR чтение/импорт** — парсинг пришедшего Structured Report (TID 5200) в доменную модель;
    импорт измерений/заключений из PACS.
16. **Graphic Annotation Presentation State (GSPS)** — сохранение калиперов/контуров/аннотаций как
    DICOM-объекта (не только в PNG/PDF), переносимость между системами.
17. **Hanging protocols** — авто-раскладка серий по правилам modality/series/view (не только ручные пресеты).
18. **DICOMDIR / CD-DVD импорт** — чтение носителей со структурой DICOMDIR, массовый импорт.
19. **Вторичный захват (secondary capture)** — экспорт текущего вида как DICOM Secondary Capture с аннотациями.

## В. Workflow / интеграция / отчётность (20–26)

20. **Входящий MWL + MPPS (#626)** — приём worklist из HIS/RIS и статусов выполнения процедуры.
21. **Worksheet → preliminary → final** — обязательные поля, handoff-верификация лаборатории,
    сборка черновика из структурированных измерений (поверх существующего lifecycle draft/signed/amended).
22. **Голосовой ввод / диктовка** — STT-ввод полей протокола/заметок (локально, офлайн-движок).
23. **Интеграция с заказами/работой** — связь с order-системой (через MWL/ORM), контекст направления.
24. **Популяционная аналитика лаборатории + QC** — агрегаты по когорте пациентов, метрики качества лабы.
25. **Пакетная обработка (batch pipeline)** — прогон папки сконфигурированным конвейером
    (seg → Simpson → strain) с сводным отчётом.
26. **Локальный индекс архива + тренды визитов** — SQLite-индекс локальных исследований, графики
    динамики индексов по пациенту/визитам.

## Г. Интерфейс и удобство (27–35)

27. **AI co-pilot quality overlay** — ненавязчивый индикатор качества/адекватности съёмки в реальном
    времени (SNR, off-axis, уверенность STE/гейтинга), кликабельный чеклист.
28. **Command palette (Ctrl+Shift+P)** — нечёткий поиск любого действия, маппинг на контракт
    `action/view/phase/extra` (D-09); единая точка команд плагинов.
29. **Контекстно-адаптивная панель** — подсветка следующего измерения, прогресс ASE «complete study»,
    предложение следующего вида для захвата.
30. **Diff-view визитов (+ карта эволюции)** — бок о бок два визита, «призрак» контура прошлого, Δ-ридоуты.
31. **Touch/перо для Presenter** — поддержка тач/пера в портативном режиме.
32. **Colorblind-safe палитра + high-contrast** — доступные цветовые схемы для strain/bull's eye.
33. **Таймлайн с маркерами фаз ED/ES** — *частично готово*: визуализировать детектированные фазы на scrubber'е.
34. **Протокол-ориентированные guided-экзамены** — *частично готово*: ASE complete-study с прогресс-баром.
35. **Облако-независимый «study capsule»** — зашифрованный бандл (измерения+кадры+подпись) для second opinion.

## Д. Исследовательские / frontier-идеи (36–48)

36. **Echo foundation model** — self-supervised vision-энкодер, дообучаемый на собственных неразмеченных
    клипах пользователя on-device; few-shot для view-rec/сегментации/качества.
37. **On-device active learning** — флаг low-confidence сегментаций, 1-клик-правка, ночное дообучение локально.
38. **Федеративная модель** — локальное обучение, обмен только дельтами градиентов (без PHI) через хаб.
39. **«Физический валидатор» (consistency engine)** — перекрёстная проверка EF↔GLS↔объёмы↔MW на
    физиологическую правдоподобность; ловит ошибки трекинга/измерения.
40. **Reader машины-HUD** — CV-чтение вшитого UI аппарата (depth/gain/подпись вида) → авто-вид и калибровка.
41. **Uncertainty-native отчётность** — каждое измерение несёт confidence, пропагируется в протокол и
    флаг «ретест».
42. **Долготовая карта эволюции / раннее предупреждение** — граф индексов по истории с детекцией аномалий.
43. **Zero-label синтетический эхо-харнесс** — дифференцируемый фантом для CI-валидации STE/MW/сегментации
    без PHI.
44. **Офлайн-LLM пре-чтение** — локальная модель черновикует заключение, проверяет ASE-полноту, предлагает
    недостающие виды.
45. **Стерильное мультимодальное управление** — речь + педаль + жест/eye-gaze для hands-free в кабинете.
46. **Второе мнение без облака** — P2P-консультация эксперта поверх encrypted study capsule.
47. **Цифровой двойник механики миокарда** — объединение STE+MW+объёмов в механическую модель,
    подсветка физио-несогласованных результатов.
48. **Адаптивная физика УЗ-изображения** — использование восстановленных параметров съёмки для
    улучшения/нормализации кадра (downstream-ИИ).

## Е. Безопасность и комплаенс (49–55)

49. **At-rest шифрование** — storage измерений / DICOM-кэш / экспорты (age-шифрование, опц. мастер-пароль/KDF).
50. **Квалифицированная ЭП через плагин** — eIDAS/УКЭП поверх `SignerPort` (локальная Ed25519 остаётся базой).
51. **Деперсонализация по DICOM PS3.15** — Basic + clean-pixel + burned-in, надстройка над `phi_mask`.
52. **Политика retention/consent** — авто-экспирация кэша по политике учреждения.
53. **Централизованная авторизация** — LDAP/AD/OIDC/SAML поверх локального multi-user (#623).
54. **Воспроизводимые сборки + GPG-подпись SHA256SUMS** — attestation релизов (#421).
55. **PHI-aware лог-редактирование по умолчанию** — расширение существующего PHI-aware tag filter.

## Ж. Плагинная архитектура (56–61)

56. **Публичный Plugin API (`sonoforge.ext`)** — консолидация существующих реестров
    (calculators, measurement_catalog, study_profiles, vendor_profiles, ports) в стабильный контракт.
57. **Официальный контракт плагина** — lifecycle init/activate/deactivate, версия API, deprecation policy.
58. **Entry-point загрузчик плагинов** — `importlib.metadata.entry_points(group="sonoforge.plugins")`,
    авто-обнаружение при старте; осторожно в Presenter.
59. **Recipe/скрипты-макросы** — протоколы и шаблоны отчётов как код (встроенный Python/Lua/JS API).
60. **UI-менеджер плагинов** — вкл/выкл, версия, подпись, зависимости.
61. **Sandbox/out-of-process для недоверенных плагинов** — изоляция исполнения (опц., фаза 3).
