# `docs/bench` — измерения и аудиты производительности

Здесь лежат **только те** измерения, на которые ссылается код, тесты, спеки или
README: цифра производительности без сохранённого отчёта — это обещание, которое
нельзя проверить. Скрипты и генераторы живут рядом с профилем работ
(`bench/`, `tests/bench/`), а сюда попадает результат: методика, условия машины,
числа, вывод и что из этого закреплено тестом.

## Правила

- Новый отчёт — файл `YYYY-MM-DD-<тема>.md` в этой папке, в git (папка больше не
  игнорируется).
- В отчёте обязательны: машина/окружение, версия кода (`git rev-parse --short`),
  команда запуска, таблица чисел, вывод «что меняем».
- Ссылки из кода и тестов идут сюда через путь
  `docs/bench/<файл>.md` (при необходимости — с номером раздела `§N.M`).
- Сырые прогоны (JSON/PNG/логи на сотни мегабайт) остаются вне репозитория:
  `bench/reports/`, `bench/la/reports/` — в `.gitignore`. Если число важно,
  оно попадает в отчёт таблицей, а не файлом.
