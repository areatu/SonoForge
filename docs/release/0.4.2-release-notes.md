# SonoForge 0.4.2 — подготовка релиза

SonoForge предназначен для исследований и обучения; результаты необходимо проверять,
программа не предназначена для принятия клинических решений.

## Изменения для пользователей

- В загрузчике с сервера можно выбрать конкретную дату исследования. Дата передаётся
  серверу и применяется к списку результатов.
- Для интервалов dP/dt на CW-спектре направляющая следует за курсором над или под
  базовой линией. Отмечаются 1 → 3 м/с для МР и 1 → 2 м/с для ТР; приложение
  вычисляет интервал и выводит результат в оверлее и отчёте.
- В кодовую базу вошли исследовательские поверхности CT/MR-стек-просмотрщика (#557),
  полуавтоматического КИМ-редактора (#558) и профили педиатрической и фетальной
  эхоКГ с Z-оценками (#650). В этом выпуске они отключены в интерфейсе — функции
  не прошли клиническую валидацию; включение возможно только явно, для разработки.
- В отчёте улучшены плотность двух колонок, состав и порядок измерений, подписи
  и сведения об источнике результата. Формализованное заключение остаётся
  черновиком для проверки врачом. Автоматические критерии и градация
  диастолической функции экспериментальны и не прошли клиническую валидацию.
- Ускорен первый вызов лупы; исправлены отображение кириллицы, навигация Tab
  в загрузчике с сервера и открытие окна strain на цветных клипах.
- Улучшены отмена фонового декодирования, защита от устаревших результатов и
  обработка завершения сохранения.
- Манифест контрольных сумм `SHA256SUMS` подписан GPG (`SHA256SUMS.asc`)
  подписывающим подключом; fingerprint опубликован в [`KEYS`](../../KEYS) и в
  [docs/security/code-signing.md](../security/code-signing.md) — проверка командами
  из раздела 3.1 этого документа.

Эта страница — подготовленные примечания, не подтверждение публикации. Перед
релизом необходимо выполнить проверки пакетов и вручную проверить итоговые
примечания GitHub Release.
