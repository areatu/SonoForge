# Splash screen — дизайн-превью и реализация

Открыть превью: **`docs/splash-preview/index.html`** (в браузере).

Страница показывает живое воспроизведение выбранного концепта **A** —
полноэкранная чёрная заставка в стиле **AnythingLLM Desktop 1.16.1**
(по описанию пользователя), включая тайминги реализации:

- прогресс: авто-шаги каждые 420 мс до ~92 %, затем 100 % — только когда
  реальная инициализация приложения завершена;
- слова появляются каскадом с 1,0 с (шаг 700 мс) — из прозрачности и
  gaussian-блюра в фокус;
- минимальное время показа 3400 мс, fade-out 420 мс; всего ~3,9 с,
  после чего «раскрывается» главное окно.

Кнопки на странице: **↻ Повторить**, **RU/EN** (слова под логотипом) и
**Приложение: тёмное/светлое** (тема раскрываемого главного окна).

Рядом — ранее предложенные альтернативы **B** («консоль УЗИ», vendor-boot)
и **C** (светлая glass-карточка).

## Соответствие описанию AnythingLLM 1.16.1

| Описание пользователя | Реализация |
|---|---|
| во весь экран, без границ | frameless-окно, геометрия = экран |
| чёрный фон | `#000000` |
| логотип | белый логотип по центру |
| проценты, снизу заполняется белым | счётчик «NN%» + тонкая белая полоса прогресса под логотипом |
| слова выходят из непрозрачности и blur в фокус | слова (`_Word`: opacity на обёртке + `QGraphicsBlurEffect` на тексте), каскад с задержкой 700 мс |
| и на этом окно закрывается | fade 420 мс в главное окно |

Слова задаются списком `splash.words` в локалях (разделитель «|»):
RU — «Локально | Конфиденциально | Стандарты ASE», EN — «Local-first |
Private | ASE aligned».

## Как включено в приложение

- `src/echo_personal_tool/presentation/splash.py` — окно `SplashScreen`,
  прогресс-бар, счётчик, слова-с эффектами. Тайминги: константы
  `MIN_VISIBLE_MS`, `AUTO_STEP_MS`, `WORD_START_MS`, `WORD_STAGGER_MS`,
  `WORD_FADE_MS`, `FADE_OUT_MS`.
- `src/echo_personal_tool/main.py` — `SplashScreen` создаётся до тяжёлой
  синхронной сборки `MainWindow`; после её создания `set_progress(46)`;
  `complete_with()` раскрывает главное окно **под** чёрной заставкой,
  затем плавный fade.
- `src/echo_personal_tool/infrastructure/locales/{ru,en}.json` — ключ `splash.words`.
- Уважается настройка доступности **Reduce motion** (слова видны сразу,
  без блюра и fade, показ короче). Отключить заставку: `ECHO_NO_SPLASH=1`.

## Тесты
