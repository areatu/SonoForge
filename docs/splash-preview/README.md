Открыть превью: **`docs/splash-preview/index.html`** (актуальный вариант 4, fullscreen).
Все варианты сохранены отдельными файлами (архив концептов):

| Файл | Вариант | Статус |
|------|---------|--------|
| `index.html` | **4 · Fullscreen logo-fill, дочищенный** (без брызг; крупные Bold-слова вокруг логотипа; крупный «NN%»; опциональный слабый фон) | **актуальный, реализован** |
| `index4-1.html` | **4.1 · Компактная карточка** 620×430 (r=26) по центру вместо fullscreen — тот же дизайн | **актуальный, реализован** (`compact=True`, `ECHO_SPLASH_COMPACT=1`) |
| `index3.html` | 3 · Заливка логотипа снизу вверх, волна + брызги, слова вокруг | архив (коммит `79728a7`) |

Навигация между вариантами — плашки сверху на каждой странице.

## Вариант 4 — дизайн

- Полноэкранное чёрное окно без границ (Qt: frameless, геометрия = экран, `#000`).
- Логотип (белый вариант) по центру; исходно еле виден (alpha ~0,10).
- По мере прогресса логотип заполняется снизу вверх белым: вторая копия
  логотипа рисуется внутри клипа с **синусоидальным краем (волна ~2,6
  периода, амплитуда 2,4 px при эталонной ширине логотипа 340 px)**.
  **Брызги и капли удалены** — единственная «грязная» деталь это волнистый
  край самой маски. К 100 % логотип полностью белый.
- Под логотипом — крупный счётчик «NN%» (`_PCT_PT_REF=22` pt, DemiBold;
  было 12 pt).
- Слова «Local-first · Private · ASE aligned» — **крупные и Bold**
  (`_WORD_PT_REF=20` pt при логотипе 340 px, DemiBold; было 14 pt/Normal),
  разложены **асимметрично** по разным высотам/расстояниям/сторонам
  относительно логотипа (`_relayout`):
  - `Local-first` — левее-выше логотипа, близко (низко над верхом);
  - `Private` — правее-выше, заметно выше и дальше от логотипа;
  - `ASE aligned` — левее-ниже, далеко вниз.
  Каждое слово исходно: opacity ~0,08 + gaussian-blur 16 px; проявляется в
  своей зоне прогресса: `Local-first 16–58 %`, `Private 34–76 %`,
  `ASE aligned 52–96 %`; к финишу полностью читаемо.
- Проценты честные: авто-шаги до ~92 % во время реального старта, 100 % —
  только после завершения инициализации (`complete_with`). Минимум показа
  3,4 с, затем fade 420 мс в главное окно (окно раскрывается под чёрной
  заставкой — без вспышки).

## Вариант 4.1 — компактная карточка

- То же содержимое, но не на весь экран: frameless-окно 620×430 по центру
  экрана, чёрная карточка со скруглением 26 px (непрозрачный центр,
  прозрачные углы, тонкая рамка). На малых экранах карточка масштабируется
  (множитель ≤ 1, минимум 0,55).
- Запуск: `SplashScreen(words=..., compact=True)`. В `main.py` — env
  `ECHO_SPLASH_COMPACT=1`.
- Финальный кадр тот же: слова читаемы, логотип белый, затем карточка
  уходит и появляется главное окно.

## Опциональный фон (плоская картинка, выключен по умолчанию)

`SplashScreen(..., background=<путь к PNG>)` рисует cover-fit картинку
(например, 4-камерное эхо) за логотипом на 20 % непрозрачности. Не добавлен
в `main.py`, чтобы не загромождать флэт-дизайн — включается только явной
передачей пути.

## Код

- `src/echo_personal_tool/presentation/splash.py`:
  - `_LogoFill` — виджет-логотип: подложка (alpha растёт с прогрессом) +
    яркая заливка внутри клипа с волнистым краем (`QPainterPath`, `QTimer`
    33 мс), без капель;
  - `_Word` — слово (создаётся с `parent=сплэш`), два вложенных эффекта
    (`QGraphicsOpacityEffect` на обёртке + `QGraphicsBlurEffect` на тексте);
  - `_WORD_ZONES` — зоны прогресса слов; `_relayout()` раскладывает слова
    вокруг логотипа асимметрично;
  - `set_progress()`, `complete_with()`, `show_and_play()`.
- `src/echo_personal_tool/main.py` — показ до сборки `MainWindow`,
  `set_progress(46)` после неё, раскрытие окна под заставкой;
  `ECHO_SPLASH_COMPACT=1` включает вариант 4.1.
- Локали `splash.words` (разделитель «|»): RU «Локально|Конфиденциально|
  Стандарты ASE», EN «Local-first|Private|ASE aligned».
- Reduce motion: слова видны сразу, без анимаций; `ECHO_NO_SPLASH=1` —
  полностью выключить.

## Тесты

`tests/unit/test_splash_screen.py` — структура (frameless, чёрный фон,
логотип, «0%», слова скрыты/в blur), крупные Bold-шрифты слов и процентов,
зоны прогресса (при 100 % всё читаемо), асимметричное расположение слов
вокруг логотипа, fullscreen-геометрия и компактная центрированная карточка,
авто-рост прогресса, завершение с раскрытием окна, reduce-motion,
env-выключатель.
