# Splash screen — дизайн-превью и реализация

Открыть превью: **`docs/splash-preview/index.html`** (в браузере).

Страница показывает три концепта и живое воспроизведение выбранного
(концепт **A**), включая тайминги реализации:

- 4 статусные строки × 850 мс;
- минимальное время показа 3400 мс;
- fade-out 360 мс;
- всего ~3,8 с, затем «раскрывается» главное окно.

Кнопки на странице: **↻ Повторить**, **RU/EN** (язык статусов) и
**Тёмная/Светлая** (заставка следует активной теме приложения).

## Концепты

| # | Название | Суть | Статус |
|---|----------|------|--------|
| A | AnythingLLM-style clinical | лого-тайл + «SonoForge» + таглайн → тонкий спиннер-дуга (акцент `#40e2de`) → строка статуса с пульсирующей точкой; тёмный градиент `#102135`, скруглённое frameless-окно, fade в главное окно | **реализован** |
| B | «Консоль УЗИ» (vendor boot) | чёрный фон, чек-лист подсистем (DICOM → ASE → AI → workspace) как на Philips/GE | предложение |
| C | Светлая glass-карточка | полупрозрачная белая карточка с мягкой тенью, синий спиннер | предложение |

## Как включено в приложение

- `src/echo_personal_tool/presentation/splash.py` — окно `SplashScreen`,
  спиннер (`_ArcSpinner`), пульс-точка (`_PulseDot`), стадии, fade.
  Тайминги: константы `MIN_VISIBLE_MS`, `STAGE_INTERVAL_MS`,
  `FADE_OUT_MS`, `SPIN_REVOLUTION_MS`.
- `src/echo_personal_tool/main.py` — `SplashScreen` создаётся до тяжёлой
  синхронной сборки `MainWindow`; статус синхронизируется с реальными
  этапами (`set_status`); `complete_with()` раскрывает главное окно
  **под** заставкой (без белой вспышки), затем плавный fade.
- `src/echo_personal_tool/infrastructure/locales/{ru,en}.json` — ключи `splash.*`.
- Уважается настройка доступности **Reduce motion** (без вращения/fade,
  короче показ). Отключить заставку: `ECHO_NO_SPLASH=1`.
