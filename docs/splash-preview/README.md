## Вариант 3 — дизайн

- Полноэкранное чёрное окно без границ (Qt: frameless, геометрия = экран, `#000`).
- Логотип (белый вариант) по центру; исходно еле виден (alpha ~0,10).
- По мере прогресса логотип заполняется снизу вверх белым: вторая копия
  логотипа рисуется внутри «водяного» клипа — синусоидальный край (волна,
  ~2,6 периода) + поднимающиеся капли-брызги (30 fps); к 100 % логотип
  полностью белый (alpha → 1,0).
- Под логотипом — небольшой счётчик «NN%».
- Слова («Local-first · Private · ASE aligned») стоят по одному вокруг
  логотипа: выше слева, выше справа, ниже слева; исходно opacity ~0,08 и
  gaussian-blur 16 px; у каждой пары своя зона прогресса, в которой слово
  проявляется до читаемого:
  `Local-first 16–58 %`, `Private 34–76 %`, `ASE aligned 52–96 %`.
- Проценты честные: авто-шаги до ~92 % во время реального старта, 100 % —
  только после завершения инициализации (`complete_with`). Минимум показа
  3,4 с, затем fade 420 мс в главное окно (окно раскрывается под чёрной
  заставкой — без вспышки).

## Код

- `src/echo_personal_tool/presentation/splash.py`:
  - `_LogoFill` — виджет-логотип с волной/каплями (`QPainterPath`-клип,
    `QTimer` 33 мс);
  - `_Word` — слово с двумя вложенными эффектами (`QGraphicsOpacityEffect`
    на обёртке + `QGraphicsBlurEffect` на тексте);
  - `_WORD_ZONES` — зоны прогресса слов; `_relayout()` раскладывает слова
    вокруг логотипа;
  - `set_progress()`, `complete_with()`, `show_and_play()`.
- `src/echo_personal_tool/main.py` — показ до сборки `MainWindow`,
  `set_progress(46)` после неё, раскрытие окна под заставкой.
- Локали `splash.words` (разделитель «|»): RU «Локально|Конфиденциально|
  Стандарты ASE», EN «Local-first|Private|ASE aligned».
- Reduce motion: слова видны сразу, без анимаций; `ECHO_NO_SPLASH=1` —
  полностью выключить.
