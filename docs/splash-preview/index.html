C · Светлая «glass»-карточка

Белая полупрозрачная карточка с мягкой тенью поверх тёмного рабочего стола, деликатный синий спиннер. Спокойно и «дорого»; удобно для светлых экранов, но ломает тёмную преемственность.

где: та же логика, светлые цвета theme_mode=light

💡 Соответствие вашему описанию 1.16.1: окно во весь экран и без границ (Qt: frameless + геометрия экрана, фон чистый чёрный #000); в центре белый логотип; под ним — тонкая полоса, заполняемая белым, и счётчик процентов; слова (RU: «Локально · Конфиденциально · Стандарты ASE») появляются по одному — из прозрачности и gaussian-блюра в фокус; затем чёрное окно растворяется (fade) в главное окно приложения. Проценты честные: авто-рост до ~92 % во время старта, 100 % — только когда реальная инициализация завершена. «Слова по сторонам» настраиваются списком splash.words в локалях — скажите, если нужно разнести их строго по левому/правому краю экрана.

Как это сделано в коде:
src/echo_personal_tool/presentation/splash.py — чёрное полноэкранное окно, логотип, «NN%» + белая полоса, слова _Word с вложенными эффектами (opacity на обёртке, QGraphicsBlurEffect на тексте) и каскадным появлением;
src/echo_personal_tool/main.py — показ до сборки MainWindow, set_progress(46) после её создания, complete_with() → 100 % → fade;
…/infrastructure/locales/{ru,en}.json — ключ splash.words (разделитель «|»);
ECHO_NO_SPLASH=1 — выключить (тесты/скриншоты). Тайминги превью повторяют реализацию.
