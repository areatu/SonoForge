# А.3 — ЭКГ-независимое фазовое поле φ(t) (issue #641, 2026-11-21)

> **Снимок на 2026-11-21.** Документ фиксирует проектные решения реализации
> `domain/services/phase_field.py` на дату ревью; актуальное состояние — в коде
> и его докстринге. Спецификация — тело issue #641 (план А.3); роутинг
> источника фазы — отдельный план А.4 (issue #642).

## 1. Выбранная ветка спеки

Issue допускает два пути: self-supervised encoder с ONNX-экспортом либо
прагматичный — комбинация image-сигналов + лёгкий регрессор. Реализован
**прагматичный путь**, но его «регрессор» — не готовая модель, а пер-клиповый
гармонический fit: усечённое разложение Фурье, минимизирующее ошибку
реконструкции по всей полосе периодов. Это и есть «periodicity loss» из спеки —
без меток, без внешних данных, без предобученных весов: обучающая выборка
регрессора — сам клип.

Почему не encoder (решение, а не отсрочка «на потом»):

- все параметры, которые учил бы encoder (период, фаза, доля систолы),
  восстанавливаются из одного клипа аналитически с гарантиями эквивариантности;
- ONNX-энкодер требует датасета, которого в репозитории нет
  (`models/` — только манифест и суммы), и не даёт точных инвариантов сдвига;
- путь к encoder оставлен открытым: `build_phase_field` принимает уже
  извлечённые кандидаты (`extract_phase_candidates`), так что будущий
  ONNX-энкодер заменит только шаг период/фаза, не трогая сигнальный слой.

## 2. Ключевые решения

1. **Период — усечённый Фурье по всей полосе, не ACF.** Линейный ACF не
   эквивариантен круговому сдвигу (окно сужается с лагом), круговой — ловит
   артефакт обрезанного удара на границе (при n=45, период 20 пик r(43) бьёт
   истинный r(20)). Adjusted R² (штраф df за 5 столбцов базиса) инвариантен к
   сдвигу/реверсию: базис при целом n/p просто переставляется. Победитель —
   **самый ранний** период в допуске 1e-4 от лучшего: на точно периодичном
   клипе все делители равны и побеждает фундаментал, длинный кандидат всегда
   проигрывает по гармоникам — ни полупериод (систола/диастола), ни удвоение.
2. **φ — чистая пила по якорям, без ES-узла.** Полный цикл линеен между
   ED-якорями, обрезанные края едут по **медианному межякорному зазору**
   (целочисленному и потому точно эквивариантному — тонко отполированный
   период даёт джиттер ±0.02 кадра, если n/p не целое). Механическая доля
   систолы читается из `PhaseFieldCycle.systole_fraction`, а не зашита в φ.
3. **Якоря — кругово, по сырому композиту.** Паддинг на полный период с двух
   сторон даёт краевому ED честную проминентность. Сглаженный сигнал для
   детекции пиков не годится: wrap-окно на несовместимом шве стягивает
   вершину; savgol poly2/wrap остаётся только там, где окна внутренние
   (ES-минимумы). `distance`-порог в find_peaks снят: копия пика через период
   у шва выигрывает тай-брейк и съедает подлинный краевой ED; под-периодные
   дубли отсеивает последующая gap-валидация [0.55, 1.6]·периода.
4. **Уверенность мультипликативна**: fit R² × согласованность носителей ×
   регулярность ритма × бонус поддержки от flow. Мультипликативность — чтобы
   каждый фактор имел право вето: аддитивная форма пропускала апериодичный
   клип с conf 0.53 при автокорреляции носителя 0.366. Ниже 0.35 — поля без
   циклов и φ≡0 («слабая догадка не должна выглядеть уверенной»).
5. **Точная эквивариантность — критерий дизайна, не настройка.** Каждый шаг
   (z-score без детренда, wrap-сглаживание, круговые якоря, качество fit)
   эквивариантен круговому сдвигу и ковариантен реверсии времени; инварианты
   из спеки (сдвиг/реверсия клипа не меняют усреднённую деформацию) выполнены
   конструктивно и покрыты `tests/unit/test_phase_field.py::TestInvariants`.

## 3. Что осознанно не сделано

- **ONNX-энкодер** — future work (см. п. 1); сейчас ни одного `.onnx`.
- **Роутинг источника фазы** — план А.4 (#642): `PhaseSource (ecg|image|hybrid)`
  в `cardiac_cycle_service`; А.3 поставляет image-путь через мосты
  `phase_field_to_ed_es_mapping` / `phase_field_ed_es_fallback`.
- **Инвариант деформации внутри модуля** — спека требует инвариантности
  downstream (strain), проверка живёт в тестах через
  `average_strain_curves`; сама служба фазы деформацию не считает.
- **Струнный контроль качества ЭКГ** — не зона А.3: поле строится только по
  изображению; смешивание с ЭКГ — зона А.4.

## 4. Ограничения

- Поле — визуальный/навигационный помощник и средство усреднения, не
  валидированное клиническое измерение (тот же контракт, что
  `cine_phase_timeline`).
- Сигнатурная точность ±1 кадр проверена на синтетике; на реальных клипах с
  мерцательной аритмией gap-валидация отберёт только регулярные удары и
  честно пометит поле `irregular_anchors`/`low_confidence`.
