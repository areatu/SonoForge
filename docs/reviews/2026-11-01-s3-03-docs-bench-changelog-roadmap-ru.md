## 2. CHANGELOG — 460 КБ одним файлом

(`v0.3.0`…`v0.3.3`) + 77 датированных записей с 2026-06-14.

| Файл | Размер | Разделов |

| `changelog/2026-06.md` | 8 КБ | 17 |

Проверка сохранности — не «на глаз»: 82 раздела исходного файла и 82 раздела
нового набора совпадают побайтово (сравнение `Counter` по разделам), суммарный
объём разделов в обе стороны — 318 000 байт. Относительные ссылки, которые в
корне разрешались от корня (`docs/superpowers/specs/…`), переписаны на
`../docs/…` — иначе после переезда они бы сломались.

Политика в шапке `CHANGELOG.md`: новый PR = одна запись в `Unreleased`; при
выпуске раздел переезжает в файл своего месяца, в `Unreleased` остаётся строка
«выпущено в vX.Y.Z».
