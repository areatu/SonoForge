## 0. Как пользоваться листом

Каждый блок содержит четыре части:

1. **Что уже закрыто автоматикой** — специально, чтобы не тратить ручное время на то, что и так проверяется в CI.
2. **Ручная приёмка** — точные действия: сборка → экран → настройка → нажатия → ожидаемый ответ → где снять доказательство.
3. **Вопросы владельцу** — с ID (UQ-…, A-…, G1-STE, …), вариантом по умолчанию и формулировкой «да/нет/иначе».
4. **Куда вернуть ответ** — комментарий в конкретный issue + (для QH) строка в `docs/reviews/`.

|---|---|
| П1 | **Не checkout.** Сборка из артефакта: Windows — `SonoForge-Setup-<ver>-x64.exe` или portable `.exe`; macOS — `.dmg`; Linux — `.deb`. Либо `gh run view --repo areatu/SonoForge` → артефакт «Build (test artifacts) → sonoforge-windows» (живёт 24 ч) |

### 1.4. Ручная приёмка UA-03 — ресайз за 4 стороны и 4 угла

1. В Windows-эксплорере убедиться, что сборка не в режиме «совместимости».
2. Навести курсор на **каждую** из 4 сторон и 4 углов границы → курсор меняется на двунаправленный, граница «горячая» ±6 px.
3. Потянуть каждую сторону и каждый угол минимум на 300 px в обе стороны.
4. Уменьшать окно до минимума → **ожидание:** размер останавливается на минимальном, ничего не наезжает друг на друга, полос прокрутки нет в строке пациента.

6. Отдельно: после `Win+Shift+←` на второй монитор ресайз-зоны работают там же.

Доказательство: 1 снимок «минимальный размер» + PASS/FAIL-строка в issue #281.

### 2.2. Порядок просмотра (30–40 минут, один заход)

Матрица = 3 пресета × 3 вида кнопок × 2 разрешения (1366×768, 1920×1080) × 2 масштаба (100 %, 150 %) × 2 локали.

Смотреть **по строкам пресетов**, для каждого проверять 5 признаков:

1. **Обрезка:** ни одна подпись не схлопнулась в «…», кроме допустимых (заголовок вкладки, имя пациента).
2. **Наложение:** ничего не перекрывает изображение; полоса шага и подсказки не лежат поверх кадра.
3. **Ритм отступов:** 8/12/16 px между группами, без «дыр» 1 px и без наезжающих бордеров.
4. **Локаль:** RU и EN читаются одинаково (EN не вылезает за панель 280–420 px), смешанной подписи нет (кириллица в EN / латиница в RU — только из белого списка, A-12).
5. **Масштаб 150 %:** шапка в 42 px не режет строку пациента, иконки рейки не «слипливаются».

Отметить проблемные файлы списком `имя.png — что не так`. Это и есть evidence.

Локальная часть (Linux tmpfs ENOSPC) уже подтверждена PASS; при желании воспроизвести:

## 12. G5a: packaged release на чистой машине

**Issue:** #188 — 0/4 · Это приёмка «артефакта, а не checkout»: без неё релиз не подтверждён.

### 12.1. Точные действия

1. **Чистая машина/ВМ:** Windows 10 21H2+, Windows 11, macOS 13+ (arm64), один Linux-дистрибутив из поддерживаемых; без установленного Python, без `~/.local/share/sonoforge`/`%LOCALAPPDATA%\SonoForge`, без моделей.
2. **Получить именно опубликованные байты** релиза (или кандидат-артефакт), сверить SHA-256 с `SHA256SUMS`, проверить attestation:
   ```sh
   sha256sum -c SHA256SUMS      # или Get-FileHash в PowerShell
   ```
3. **Установить и запустить** (Setup для «for me» без UAC; «for all users» — с UAC; portable — без установки; `.deb` — `sudo apt install ./sonoforge_*.deb`).
4. **Full profile:** скачать модели по первому диалогу → затем обязательная цепочка **save → restart → export**:
   - открыть DICOM, 3+ измерения (линейка, Simpson, допплер), калибровка;
   - «Сохранить» → закрыть приложение → открыть → измерения/калибровка восстановлены;
   - экспорт PDF/печать → файл открывается, совпадает с экраном.
5. **Presenter profile** (`SonoForgePresenter-<ver>.exe` / AppImage с USB-флешки): запуск без прав админа, `F10` → показ на второй экран, лазерная указка, пресет «проектор», отсутствие AI-функций и ясная деградация (A-11).
6. **Manifests/provenance/SBOM:** каждый пункт release notes ссылается на **опубликованные** ассеты; хеши в `latest.json` соответствуют фактическим размерам/хешированным байтам; SBOM относится к сборке, а не к репозиторию.
7. **Build/release CI:** убедиться, что `pip install -e` больше нет в обязательных джобах, sync идёт по `uv.lock` (`uv sync --locked`), матрица платформ и профилей документирована.
