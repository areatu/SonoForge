## Решения владельца в текущей сессии

1. **#176 / S-02:** при отключённой persistence сохранять ручную калибровку и BSA в памяти для исходной вкладки и восстанавливать при возвращении; не переносить между вкладками, не записывать на диск. Это **решение о требуемом поведении**, не заявление, что оно уже реализовано. До реализации и тестов старое поведение остаётся в силе.
2. **#176 / G1:** ручной чеклист вести как отдельную приёмку, а не обязательное условие автоматического/нативного G1. Само решение не означает, что G1 или ручная приёмка прошли: сначала нужно сверить остальные критерии и записать evidence. Проверки C1/C2, D1–D3, E1–E3, F1–F5 не отменяются.
3. **#421:** целевая политика — релиз без GPG-подписи checksum manifest не публиковать (fail-closed). Это **ещё не настройка ключа и не доказательство**: нужны владелец ключа, защищённая настройка, закреплённый публичный fingerprint и проверка опубликованных assets. Текущий release workflow всё ещё допускает unsigned при отсутствии секрета; до реализации политики это расхождение должно быть видно. OS code signing/notarization — отдельный #189.
4. **#288:** не утверждать UQ-01…UQ-12 пакетом; подготовить таблицу решений по одному вопросу. Значения спеки пока рабочие defaults, а не доказательство согласования клинических текстов или ручной приёмки.
