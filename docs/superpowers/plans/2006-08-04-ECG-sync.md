### 1. Цели ECG-синхронизации

Сделать ECG **единым источником истины** для границ сердечного цикла везде, где это повышает точность и воспроизводимость:

1. **Spectral Doppler (VTI, mitral inflow, TR и т.д.)** — границы цикла для auto-trace и ручного VTI.
2. **Vessel Doppler (сонные / позвоночные)** — точное определение PSV/EDV внутри одного (или нескольких) циклов.
3. **CINE B-mode / Strain / LVEF** — ED/ES (уже частично есть).
4. **Multi-beat averaging** — усреднение PSV/EDV/VTI/strain по 2–5 циклам.
5. **Визуализация** — ECG-лента + маркеры R-пиков + подсветка текущего цикла.

### 2. Единый сервис цикла (новый слой)

Создать `domain/services/cardiac_cycle_service.py` (или расширить существующий):

```text
class CardiacCycleService:
    def get_cycles(
        self,
        *,
        ecg: EcgWaveform | None,
        frame_time_ms: float | None,      # для CINE
        n_frames: int | None,
        spectrogram_time_axis_ms: np.ndarray | None,  # для Doppler
        fallback_signal: np.ndarray | None = None,    # intensity / area
    ) -> list[CardiacCycle]
```

`CardiacCycle`:
```python
@dataclass
class CardiacCycle:
    start_ms: float          # начало (≈ R-peak или ED)
    end_ms: float            # конец (следующий R-peak − ε)
    r_peak_ms: float
    ed_ms: float             # обычно = r_peak_ms
    es_ms: float             # ≈ r_peak + 0.35 * RR
    source: str              # "ecg" | "image" | "manual"
    confidence: float
```

Приоритет источников:
1. ECG (confidence ≥ 0.4)
2. Image-based (FFT / area / spectral envelope shape)
3. Manual (пользовательские полосы)

### 3. Где именно применять ECG

#### 3.1. Vessel Doppler (auto-trace PSV/EDV) — **высокий приоритет**

**Текущее поведение:** пользователь ставит левую/правую полосу → auto-trace → PSV = max, EDV = последняя точка.

**С ECG:**
- Автоматически предлагать границы цикла по ближайшим R-пикам.
- PSV = max огибающей **внутри** цикла.
- EDV = значение огибающей в момент, ближайший к **следующему R-пику** (или локальный минимум в последних 20–30 % цикла).
- Кнопка «Snap to ECG cycle».
- Возможность усреднить 2–3 соседних цикла.

#### 3.2. Spectral Doppler VTI / mitral / TR

- Auto-trace ограничен одним ECG-циклом.
- Onset VTI = R-peak (или чуть раньше для mitral E).
- Для regurgitation (TR/PR) — цикл может быть смещён.
- Multi-beat VTI average.

#### 3.3. CINE B-mode / LVEF / Strain

- Уже есть `map_rpeaks_to_frames`.
- Нужно: всегда предпочитать ECG, если он есть и confidence высокий; иначе fallback.
- Показывать R-пики на timeline CINE.
- Авто-выбор ED/ES при открытии исследования.

#### 3.4. Multi-beat averaging (общий механизм)

Для любого измерения, которое зависит от цикла:
```text
result = average([measure(cycle_i) for cycle_i in selected_cycles])
```
UI: чекбоксы циклов + «Average selected».

### 6. Детали для Vessel (самый актуальный сейчас)

**Этап A. Единый сервис циклов `CardiacCycleService`:**

```python
@dataclass
class CardiacCycle:
    start_ms: float
    end_ms: float
    r_peak_ms: float
    ed_ms: float
    es_ms: float
    source: Literal["ecg", "image", "manual"]
    confidence: float
    rr_ms: float | None = None
```

Источник цикла приоритезируется: ECG (confidence ≥ 0.4) → image (FFT/area) → manual.
Для Doppler/Vessel image-фолбэк — колоночный профиль яркости спектра или огибающая.

**Выравнивание времени (этап C, авто-кросс-корреляция):**

```text
1. extract_doppler_envelope → колоночный профиль яркости/максимальной скорости.
2. Резэмплить профиль на шкалу времени ECG (от начала waveform-секвенции).
3. xcorr(profile, ecg_signal) → сдвиг offset_ms; сдвиг применяется ко всем R-peak time.
4. Если корреляция слабая (ниже порога) → fallback на image-циклы.
```

**Алгоритм `derive_psv_edv_with_ecg`:**

```text
1. cycles = CardiacCycleService.get_cycles(ecg=..., spectrogram_time=..., fallback=profile)
2. Если есть ECG-циклы → взять выбранный (или ближайший к текущим полосам)
3. Обрезать envelope по [cycle.start_ms, cycle.end_ms]
4. PSV = max(envelope) внутри цикла (минимум y)
5. EDV = локальный минимум скорости в последних 20–30 % цикла
   (без сглаживания; маркер ставится в точку минимума, значение читается из маркера)
6. Если ECG нет → текущая логика (derive_psv_edv_indices) + пометка source="image"/"manual"
```

**UI-поток (этап C, минимальный):**
1. Пользователь нажимает Auto-Trace.
2. Если ECG доступен → границы цикла автоматически ставятся по R-пикам, огибающая строится, PSV/EDV считаются по правилам выше.
3. Пользователь может подвинуть границы/калиперы (ручная коррекция).
4. Accept. В измерение попадает `source` цикла (для аудита).

**Подключение ECG в сессию (этап C):**
- При активации Doppler/Vessel для активного instance: `dicom_session.parse_waveform()` → `EcgWaveform` → кэш в session/state.
- R-пики: `detect_r_peaks()`; выравнивание: кросс-корреляция; границы цикла → в Vessel flow.
