**Алгоритм авто-трейсинга огибающей спектрального допплера**
(для SonoForge, этап после калибровки, работа на одном кадре / коротком клипе)

### 1. Цель и область применения
Автоматически извлечь **максимальную огибающую** (peak-velocity envelope) спектрального допплера, чтобы:
- сразу получать PSV, EDV и суррогатные индексы (RI, S/D, MV≈);
- дать пользователю возможность быстро скорректировать трейс вручную;
- в будущем перейти к multi-beat усреднению и artery-specific ratios.

**Ограничения текущей версии:**
- Работаем после успешной калибровки (velocity scale, zero-line, направление известны).
- Один кадр или короткий клип (несколько сердечных циклов).
- Только **max-envelope** (верхняя огибающая). Mean-envelope — опционально позже.
- Предпочтение прозрачному, настраиваемому классическому алгоритму (без тяжёлого ML на первом этапе).

### 2. Рекомендуемый алгоритм (гибрид лучших практик)

Используем проверенный пайплайн, который хорошо работает на реальных клинических спектрах (threshold + morphological + column-wise max + smoothing). Он близок к тому, что применяют в коммерческих offline-системах и в работах по automatic envelope detection.

#### Этапы

**A. Подготовка изображения спектра**
1. Взять ROI спектра (уже известен после калибровки / детекции спектрального окна).
2. Конвертировать в grayscale (если ещё не).
3. Лёгкое шумоподавление: bilateral filter или Gaussian (σ ≈ 1–1.5).
4. (Опционально) CLAHE для повышения контраста слабых спектров.

**B. Оценка шума и адаптивный порог**
1. Взять верхние 10–20 % частотных бинов (или область выше ожидаемого максимального сигнала) → оценка mean_noise и std_noise.
2. Альтернатива / дополнение: Otsu или percentile на всей колонке.
3. Порог для каждой временной колонки (или глобальный с лёгкой адаптацией):
   ```
   threshold = mean_noise + k * std_noise
   ```
   или
   ```
   threshold = max(mean_noise * factor, percentile(column, p))
   ```
   Типичные стартовые значения: k = 3…5, factor = 1.5–2.5 (настраиваемые).

**C. Бинаризация + морфология**
1. Бинаризация: pixel > threshold → 1.
2. Удаление мелкого шума: opening (маленький структурный элемент).
3. Заполнение дыр внутри спектра (closing или flood-fill по колонкам).

**D. Извлечение сырой огибающей (column-wise)**
Для каждой временной колонки t:
- Ищем **самый высокий** (максимальная скорость) пиксель, равный 1, начиная сверху вниз (или снизу вверх в зависимости от направления потока и baseline).
- Если сигнал не найден → интерполяция от соседних колонок или пометка как “gap”.

Это даёт сырую дискретную огибающую `v_raw[t]`.

**E. Сглаживание и физиологические ограничения**
1. Медианный фильтр (окно 3–7) — убирает выбросы.
2. Savitzky-Golay или лёгкий spline / cubic interpolation.
3. (Опционально) ограничение на максимальную скорость изменения (физиологический constraint) — защита от скачков из-за артефактов.

**F. Детекция характерных точек (для одного / нескольких циклов)**
- Поиск локальных максимумов → кандидаты PSV.
- Поиск локальных минимумов в диастолической части → кандидаты EDV.
- Если несколько циклов — выбираем самый высокий PSV и соответствующий EDV (или среднее — настраиваемо).

**G. Расчёт суррогатов** (как в предыдущей спеке)
```
RI  = (PSV − EDV) / PSV
S/D = PSV / EDV
MV≈ = (PSV + 2×EDV) / 3
```

### 3. План реализации (поэтапный)

| Этап | Что делаем | Результат | Приоритет |
|------|------------|---------|---------|
| 1 | Pipeline A–E на одном кадре (max-envelope) | Сырой + сглаженный трейс | Высокий |
| 2 | Авто-поиск PSV/EDV + оверлей результатов | Мгновенные числа в UI | Высокий |
| 3 | Возможность ручной коррекции трейса (drag точек / перерисовка сегментов) | Клиническая пригодность | Высокий |
| 4 | Настраиваемые параметры порога + пресеты (Low / Medium / High SNR) | Устойчивость | Средний |
| 5 | Поддержка нескольких циклов + выбор “best cycle” | Улучшение точности | Средний |
| 6 | Mean-envelope + VTI (по площади под огибающей) | Расширение | Низкий |
| 7 | (Будущее) Max-likelihood / лёгкая CNN-регрессия огибающей | Максимальная robustness | Позже |

### 4. Спецификация интерфейса и поведения

**Активация**
- После успешной калибровки + `is_spectral_doppler == True`.
- Кнопка в секции «Сосуды» / панели Measurements: **«Auto-Trace»**.

**Поведение**
1. Пользователь нажимает Auto-Trace → алгоритм выполняется.
2. На спектре появляется цветная огибающая (например, жёлтая/циановая).
3. В оверлее результатов сразу:
   ```
   PSV:  xxx.x cm/s
   EDV:  xxx.x cm/s
   RI:   0.xx
   S/D:  x.xx
   MV≈:  xxx.x cm/s
   ```
4. Пользователь может:
   - Перетащить отдельные точки огибающей.
   - Удалить сегмент и перерисовать.
   - Нажать «Re-trace» с другими параметрами порога.
   - Принять (Accept) → сохранение в Measurements.

**Сохраняемый объект** (расширение предыдущего):
```json
{
  "type": "vessel_doppler_autotrace",
  "frame_id": "...",
  "envelope": [[t1, v1], [t2, v2], ...],   // в см/с
  "PSV": ...,
  "EDV": ...,
  "RI": ...,
  "SD": ...,
  "MV_approx": ...,
  "params": { "threshold_k": 4.0, "smooth_window": 5, ... },
  "manual_edited": false
}
```
