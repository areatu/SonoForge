**Спецификация (обновлённая): ручное измерение PSV / EDV на одном кадре + суррогатные показатели**

### 1. Цель
После завершения калибровки спектра реализовать простой режим ручного измерения **PSV** и **EDV** на **одном кадре**.
В оверлее результатов сразу отображаются:
- PSV
- EDV
- все суррогатные показатели, вычисляемые **только** из этих двух значений (без привязки к конкретной артерии и без ratios ICA/CCA и т.п.).

### 2. Условия активации

Режим доступен **только** когда:
1. Калибровка спектра успешно завершена (scale, zero-line, единицы см/с известны).
2. Текущий кадр определён как спектральный допплер (`is_spectral_doppler = True`).
3. Пользователь находится в режиме просмотра одного кадра.

При невыполнении условий кнопки измерения disabled.

### 3. Интерфейс

**Новая секция:** `Сосуды` (в боковом меню / вкладках режимов).

**Панель Measurements → группа «Vessel Doppler (manual)»:**

```
┌─ Vessel Doppler (manual) ─────────────────────┐
│                                               │
│  [PSV]   [EDV]   [Clear]   [Accept]           │
│                                               │
│  Статус:  Ожидание PSV / Ожидание EDV / Готово│
│                                               │
└───────────────────────────────────────────────┘
```

**Оверлей результатов** (поверх спектра, полупрозрачный блок в углу кадра):

```
PSV:   178.4 cm/s
EDV:    62.1 cm/s
────────────────
RI:     0.65
S/D:    2.87
MV≈:   100.9 cm/s
```

Оверлей появляется автоматически после размещения обоих calipers и обновляется в реальном времени при перемещении точек.

### 4. Процесс измерения (один кадр)

1. Пользователь нажимает **PSV** → ставит вертикальный caliper на пик систолы.
2. Нажимает **EDV** → ставит второй caliper на конечно-диастолическую точку.
3. Система сразу считает суррогаты и показывает оверлей.
4. Пользователь может перетаскивать любой caliper — значения и оверлей обновляются на лету.
5. **Clear** — удаляет оба caliper’а и скрывает оверлей.
6. **Accept** — фиксирует измерение в списке Measurements текущего исследования.

**Горячие клавиши:**
`P` — PSV, `E` — EDV, `Enter` — Accept, `Esc` — Clear.

### 5. Расчёты (только из PSV и EDV)

```text
RI   = (PSV − EDV) / PSV          (если PSV > 0)
S/D  = PSV / EDV                  (если EDV > 0)
MV≈  = (PSV + 2 × EDV) / 3
```

**Округление:**
- скорости → 1 знак после запятой
- RI и S/D → 2 знака после запятой

**Проверки:**
- Если PSV ≤ EDV → предупреждение в оверлее «Проверьте точки».
- Если EDV ≤ 0 → S/D и RI не рассчитываются.

### 6. Сохранение

При `Accept` сохраняется объект:

```json
{
  "type": "vessel_doppler_manual",
  "frame_id": "...",
  "PSV": 178.4,
  "EDV": 62.1,
  "RI": 0.65,
  "SD": 2.87,
  "MV_approx": 100.9,
  "calibration_id": "...",
  "timestamp": "..."
}
```

Измерение появляется в общем списке Measurements с возможностью редактирования (возврат к calipers) и удаления.

### 7. Ограничения текущей версии

- Работа **только на одном кадре** (без усреднения по циклам).
- Нет выбора сегмента / стороны / артерии.
- Нет artery-specific ratios (ICA/CCA, St. Mary’s и т.д.).
- Нет snap-to-envelope (пока чисто ручные calipers).

---

Спека максимально упрощена под текущий этап: калибровка → один кадр → PSV + EDV → мгновенный оверлей с суррогатами.
