**Обновлённая спецификация: Auto-Trace огибающей спектрального допплера**
(с учётом ваших ответов)

### 1. Цели текущей версии
- Быстрый, простой и предсказуемый авто-трейс **одного** сердечного цикла.
- Пользователь вручную указывает границы цикла (левая и правая вертикальные полосы).
- Поддержка **bidirectional** потока (положительная и отрицательная огибающие).
- Хорошая ручная коррекция после авто-трейса.
- Пресеты чувствительности сразу.
- Источник данных: **числовой spectrogram** (основной путь), fallback — пиксельное изображение.

### 2. Входные данные

**Основной путь (предпочтительный):**
```python
spectrogram: np.ndarray          # shape (n_time, n_freq), float, интенсивность
velocity_axis: np.ndarray        # shape (n_freq,), см/с (уже после калибровки)
time_axis: np.ndarray            # shape (n_time,), секунды
zero_line_idx: int               # индекс baseline
cycle_left_idx: int              # левая граница цикла (вручную)
cycle_right_idx: int             # правая граница цикла (вручную)
```

**Fallback:**
- Если числового массива нет → работаем с ROI пиксельного изображения спектра + используем уже известную калибровку (velocity scale + zero-line).

### 3. Алгоритм (максимально простой и быстрый)

#### Шаг 0. Подготовка
- Обрезаем spectrogram по `cycle_left_idx : cycle_right_idx`.
- Разделяем на две половины относительно `zero_line_idx`:
  - `pos_half` — выше baseline (положительные скорости)
  - `neg_half` — ниже baseline (отрицательные скорости)

#### Шаг 1. Оценка шума (по пресету)
Пресеты «Чувствительность трейса»:

| Пресет       | Описание                    | k (множитель std) | Доп. параметры          |
|--------------|-----------------------------|-------------------|-------------------------|
| Low noise    | Чистый сигнал               | 2.5               | слабое сглаживание      |
| Normal       | Обычный клинический спектр  | 3.5–4.0           | стандарт                |
| High noise   | Слабый / шумный спектр      | 5.0–6.0           | более агрессивный порог |

- Шум оцениваем в верхних 15–20 % частотных бинов каждой половины (или в областях без сигнала).
- `threshold = mean_noise + k * std_noise`

#### Шаг 2. Извлечение сырой огибающей (column-wise)
Для каждой временной колонки внутри цикла:

**Положительная огибающая:**
- Идём от самых высоких частот вниз к baseline.
- Берём **первый** бин, где intensity > threshold → `v_pos[t]`

**Отрицательная огибающая:**
- Идём от самых низких частот вверх к baseline.
- Берём **первый** бин, где intensity > threshold → `v_neg[t]`

Если в колонке сигнал не найден → линейная интерполяция от соседей + пометка gap.

#### Шаг 3. Сглаживание
- Медианный фильтр (окно 3 или 5 в зависимости от пресета).
- Лёгкий Savitzky-Golay (window=5–7, polyorder=2) или простое скользящее среднее.
- Никаких сложных физиологических constraints на первом этапе.

#### Шаг 4. Поиск PSV / EDV
- На положительной огибающей:
  - PSV = максимум
  - EDV = значение в конце цикла (или локальный минимум в последней 30 % цикла)
- Аналогично для отрицательной огибающей (если она значима).
- Если обе огибающие присутствуют — показываем обе пары PSV/EDV + даём пользователю выбрать «основную».

#### Шаг 5. Суррогаты (как раньше)
```
RI  = (PSV - EDV) / PSV
S/D = PSV / EDV
MV≈ = (PSV + 2*EDV) / 3
```

### 4. UI / Взаимодействие

**Последовательность действий пользователя:**
1. Калибровка выполнена.
2. Пользователь ставит **две вертикальные полосы** (левая и правая граница цикла) — простые draggable guides.
3. Выбирает пресет чувствительности (Low / Normal / High noise) — по умолчанию Normal.
4. Нажимает **Auto-Trace**.
5. Появляются:
   - Цветная огибающая (cyan — positive, magenta — negative).
   - Оверлей с PSV, EDV, RI, S/D, MV≈.
6. Ручная коррекция:
   - Перетаскивание отдельных точек огибающей.
   - Удаление сегмента + перерисовка мышью.
   - Кнопка «Re-trace» (с тем же или другим пресетом).
7. Accept → сохранение.

**Кнопки в панели:**
- `[Указать цикл]` (или автоматически активируется при входе в режим)
- Пресет: `Low | Normal | High`
- `[Auto-Trace]`
- `[Clear Trace]`
- `[Accept]`

### 6. План реализации (приоритеты)

1. **Core**
   - Функция `extract_envelope(spectrogram, velocity_axis, zero_line, left, right, preset)`
   - Возвращает pos/neg envelopes + PSV/EDV.

2. **UI guides**
   - Две вертикальные draggable полосы для указания цикла.

3. **Отрисовка огибающей + оверлей результатов**.

4. **Ручная коррекция** (перетаскивание точек + простой redraw).

5. **Пресеты** + Re-trace.

6. **Fallback** на пиксельное изображение (если числового spectrogram нет).

7. Позже: авто-поиск границ цикла, multi-cycle, mean-envelope, VTI.

### 7. Рекомендуемые значения по умолчанию (Normal)

- k = 3.8
- median_window = 5
- savgol_window = 7, polyorder = 2
- min_signal_length = 5 колонок (иначе gap)
