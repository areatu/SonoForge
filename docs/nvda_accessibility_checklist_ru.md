# Ручной чек-лист проверки доступности с экранным диктором NVDA (Windows)

Короткий сценарий ручной проверки доступности перед релизом (issue `#484`, развивает `#313` и `#286` UA-19 «Только клавиатура»).
Автоматические проверки имён, описаний и порядка фокуса выполняются в CI (`tests/unit/test_accessibility_and_i18n_484.py` и `tests/unit/test_report_accessibility.py`), однако реальное произношение синтезатором речи проверяется вручную на Windows 10/11 с бесплатным экранным диктором **NVDA**.

## Подготовка

1. Запустить **NVDA** (`Ctrl+Alt+N`), включить окно просмотра речи (**NVDA → Сервис → Просмотр речи** / *Speech Viewer*), чтобы визуально сверять каждую реплику диктора.
2. Запустить **SonoForge** без использования мыши (навигация только `Tab`, `Shift+Tab`, стрелками, `Space`, `Enter`, `Esc`).

## 1. Основной клинический сценарий (открыть → калибровка → контур → результат → отчёт)

1. **Шапка и системная строка**:
   - Пройти `Tab` по заголовку окна и системной панели: кнопка меню приложения озвучивается как *«Меню приложения»* (а не пустая кнопка), кнопки управления окном — *«Свернуть»*, *«Развернуть»*, *«Закрыть»*, кнопка закрытия вкладки — *«Закрыть вкладку …»*.
   - Фокус на кнопке открытия папки озвучивает название *«Открыть папку…»* и описание действия; `Space`/`Enter` открывает системный диалог выбора исследования.
2. **Калибровка и инструменты измерений**:
   - После открытия клипа пройти `Tab` по панели/рейлу инструментов (`Калибровка`, `Калипер`, `Площадь`/`Контур`, `Авто ФВ ЛЖ`, `Оверлей результатов`, `Панели`).
   - Проверить, что даже в компактном режиме (только иконки) каждая кнопка произносит осмысленное русское название и описание (`accessibleName` / `accessibleDescription`), а не «кнопка» без имени.
3. **Транспорт видеопетли и оверлей результатов**:
   - В нижней панели вьювера кнопки транспорта (все иконочные, без текста) озвучиваются как *«Первый кадр»*, *«Шаг назад (предыдущий кадр)»*, *«Воспроизведение»* / *«Пауза»*, *«Шаг вперёд (следующий кадр)»*, *«Последний кадр»*.
   - При переключении `Space` на кнопке воспроизведения имя меняется с *«Воспроизведение»* на *«Пауза»* без потери фокуса.
4. **Переход в режим «Отчёт» (`Ctrl+R` или переключатель режима)**:
   - Переключатели *«Изображения»* / *«Отчёт»* озвучивают название и назначение режима.

## 2. Проверка Tab-order и работы только с клавиатуры (UA-19)

1. **Режим «Отчёт»**:
   - Начиная с первого поля карточки пациента (`ФИО`), последовательное нажатие `Tab` проводит фокус сверху вниз по полям пациента (`ФИО` → … → `Пол`), затем в правую колонку фраз и заключения (`Поиск фразы` → `+ Своя` → `Импорт` → `Экспорт` → поле `Заключение` → `Сформировать черновик`), и далее по блоку экспорта (`PDF…` → `CSV…` → `JSON…` → `Печать…` → `Завершить`) без скачков назад в шапку в конце цепочки.
2. **Диалог «Настройки» (`Ctrl+,`)**:
   - `Tab` проходит: поле поиска параметра → список разделов (`Разделы настроек`, стрелки `↓`/`↑` переключают страницы настроек) → элементы управления текущего раздела (каждый чекбокс без подписи справа озвучивает заголовок своей строки, а не безымянный «флажок») → кнопки нижней панели (`Сбросить раздел` → … → `Готово`) → кнопка `Закрыть`.
   - `Esc` закрывает диалог без сохранения; `Enter` на `Готово` сохраняет настройки.
3. **Диалог PACS / сервера (`Загрузить с сервера…`)**:
   - `Tab` проходит в порядке чтения: поле поиска пациента → `Найти` → `Источник` → `Сортировка` → `Миниатюры` → фильтр периода → массовый выбор → фильтры режимов/аппарата/модальности → список исследований → `Выбрать все серии` / `Снять выбор` → список серий → кнопки `Открыть` / `Сохранить на диск` / `Отмена` → `Закрыть`.

## 3. Переключение языка (RU ↔ EN)

1. В диалоге «Настройки» переключить язык интерфейса на **English** и применить изменения.
2. Повторить быстрый проход `Tab` по шапке, системной строке, транспорту вьювера и блоку экспорта отчёта: все `accessibleName` и `accessibleDescription` озвучиваются на английском языке без перезапуска приложения, порядок фокуса не меняется.
