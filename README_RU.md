# SonoForge

### Открытая платформа для анализа эхокардиографии

**SonoForge** — бесплатное открытое десктопное приложение для **анализа эхокардиографических исследований**, **просмотра DICOM**, **кардиологических измерений** и **клинической отчётности**. Создано для кардиологов, сонографов и исследователей, которым нужен мощный офлайн-инструмент, соответствующий **рекомендациям ASE (Американское общество эхокардиографии)**.

Для демонстраций вне рабочей станции существует лёгкое портативное издание —
**[SonoForge Presenter](build/presenter/README.md)** — запускается прямо с USB-флешки:
один файл, без установки, со всеми инструментами измерений и подключением к PACS.

## SonoForge Presenter — DICOM как презентация

![SonoForge Presenter](assets/presenter.png)

![Демонстрация режима докладчика](assets/presenter_demo.gif)

Портативное издание SonoForge для лекций и разбора случаев: **у аудитории — чистый
полноэкранный просмотр эхо, у вас — все инструменты измерений**. Как показ слайдов в
PowerPoint, только вместо слайдов — живой DICOM.

1. **У вас — рабочая станция, у аудитории — чистый экран.** Выбираете дисплей аудитории;
   второй экран показывает только изображение, во весь экран.
2. **Всё зеркалится в реальном времени** — контуры по точкам и freehand, правка узлов,
   калиперы, допплер/VTI, сосудистые PSV/EDV, оверлей результатов: аудитория видит каждую
   правку мгновенно.
3. **Фишки докладчика** — выбор дисплея аудитории, лазерная указка, визуальный профиль
   проектора (толстые линии, крупные подписи).
4. **Запускается с флешки** — один файл, без установки и прав администратора, без моделей
   AI; Windows и Linux.

Нажмите `F10` → докладывайте. Скачайте `SonoForgePresenter-<version>.exe` (Windows) или
`SonoForge-Presenter-<version>-x86_64.AppImage` (Linux) в разделе
[Releases](https://github.com/areatu/SonoForge/releases); подробности —
[build/presenter/README.md](build/presenter/README.md).

## Установка

<details open>
<summary><strong>Linux (.deb) — Рекомендуется</strong></summary>

1. Откройте [Releases](https://github.com/areatu/SonoForge/releases) и скачайте версионированный пакет `sonoforge_<version>_amd64.deb`.
2. В каталоге со скачанным файлом установите пакет и запустите приложение:

```bash
sudo apt install ./sonoforge_*.deb
sonoforge
```

При первом запуске создаётся пользовательское виртуальное окружение и устанавливаются Python-зависимости. Лаунчер предложит скачать AI-модели для сегментации; после отказа приложение может дополнительно показать диалог настройки, в котором загрузку также можно пропустить. Остальные функции доступны и без моделей, автоматическая сегментация — нет. Каталог данных определяется `XDG_DATA_HOME` (по умолчанию `~/.local/share/sonoforge`).

</details>

<details>
<summary><strong>Windows (установщик; также доступна portable-версия .exe)</strong></summary>

1. Откройте [Releases](https://github.com/areatu/SonoForge/releases/latest), скачайте **`SonoForge-Setup-<version>-x64.exe`** и запустите файл.
2. Выберите установку **для меня** (по умолчанию, без UAC) или **для всех пользователей** (потребуются права администратора). Установщик создаёт ярлыки в меню «Пуск» и на рабочем столе; запускать SonoForge можно любым из них.
3. При первом запуске приложение предложит скачать AI-модели для сегментации. Загрузку можно пропустить; тогда автоматическая AI-сегментация будет недоступна.

Чтобы удалить приложение, откройте Windows **Параметры → Приложения → Установленные приложения** (в Windows 10 — **Приложения и возможности**) и выберите SonoForge либо воспользуйтесь панелью управления **Программы и компоненты**. Удаление убирает приложение и ярлыки, но по умолчанию сохраняет `%LOCALAPPDATA%\SonoForge`. Выберите в деинсталляторе **Also remove SonoForge user data** только если нужно удалить также модели, кэш, журналы и настройки этой учётной записи.

> **Требуется:** Windows 10/11 (64-бит). Установщик и portable-сборка не подписаны Authenticode, поэтому Windows SmartScreen при первом запуске может показать *«Компьютер защищён Windows»* / **Неизвестный издатель** — выберите **Подробнее → Выполнить в любом случае**. Каждый файл релиза снабжён подписанным подтверждением происхождения сборки (build provenance attestation) и перечислен в приложенном `SHA256SUMS`; обе проверки описаны в разделе [Проверка загруженного файла](docs/security/code-signing.md#3-verifying-a-download).

Зависимости приложения уже включены; устанавливать Python и виртуальное окружение не нужно. Для запуска без установки скачайте **`SonoForge-<version>-portable.exe`** с той же страницы релиза. Portable-файл не создаёт ярлыки; данные приложения по-прежнему хранятся в каталоге данных текущего пользователя Windows.

</details>

3. Дважды щёлкните для запуска

Настройки, профили PACS, зашифрованные токены паролей, DICOM-кэш и журналы приложения

отключить очистку при выходе. Все инструменты измерений и подключение к PACS включены;
AI-сегментация (ONNX) и интерфейс Конструктора справочника в это издание не входят.
Подробности: [build/presenter/README.md](build/presenter/README.md).

## Возможности

SonoForge предоставляет комплексный набор инструментов для **эхокардиографической оценки** — от базовых измерений до продвинутого AI-анализа.

### Кардиологические измерения

- **Ввод контура ЛЖ** — Три ориентира (септальное кольцо, латеральное кольцо, верхушка) или свободная трасса; выбирается в «Настройки → Измерения → Ручной контур ЛЖ». Свободный штрих не проходит магнитную привязку и оптическую коррекцию. См. [тур по функциям](https://areatu.github.io/SonoForge/tour.html)

| Категория | Измерения | Описание |
|-----------|-----------|----------|
| **Линейные (M-Mode/B-Mode)** | КДР, КСР, МЖП, ЗСЛЖ, ТАПСЕ, ПЖЖ | Стандартные линейные измерения ASE с подписями в реальном времени |
| **Объёмные (Simpson биплан)** | ОДВ, ОСВ, ФВЛЖ, ОПЛЗ, ОППЗ | Метод Симпсона с отслеживанием митрального кольца |
| **M-Mode** | Толщина задней стенки, размеры ЛЖ, ФС | Измерения времени-глубины с линией сканирования |
| **Функция ПЖ** | ФАП (фракционная площадь изменения), ТАПСЕ | Оценка правого желудочка |
| **Масса ЛЖ** | МЛЖ, ЛМИ (индексация по ВТС), ОСС | Геометрический и анатомический расчёт массы |
| **Площадь тела** | Формула Дюбуа, индексированные измерения | Автоматическая индексация по площади тела |
| **ЧСС по ЭКГ** | Частота сердечных сокращений из ЭКГ | Автоматическое определение ЭД/ЭС по R-пикам ЭКГ |

### Допплер и сосудистые измерения

- **Пики PSV/EDV** — Ручные измерения пиков на спектральном допплере с автоматическим расчётом индексов RI и S/D
- **Калипер в зоне допплера** — Внутри откалиброванной зоны ROI допплера общий калипер измеряет Δt (мс) и амплитуду скорости (см/с или м/с) вместо расстояния (например AcT RVOT); в зоне B-mode снова измеряется расстояние
- **Непрерывный калипер** — Пока инструмент активен, каждая пара кликов фиксирует измерение (Dist1, Dist2, …) и сразу начинает следующее, как на УЗ-сканере; результаты хранятся только внутри своего файла
- **Стеноз сосуда** — По диаметру (%D) и по площади (%S) с пошаговыми сценариями измерения
- **Усреднение без ЭКГ** — Усреднение PSV/EDV по автоматически выявленным кардиоциклам с ручным выбором цикла
- **Auto VTI** — Выделение зоны двумя кликами с определением направления, фильтрацией артефактных пиков и построением VTI-трассы
- **Сквозные измерения по исследованию** — Сохранение измерений между файлами одного исследования (E-пик на одном файле + e' на TDI -> среднее E/e' в оверлее)

### Автокалибровка допплера

- **Определение шкалы скоростей** — Автоматическая калибровка по тикам линейки с fallback на линии сетки
- **Калибровка скорости развёртки** — Детектор тиков Samsung RS85 для временной оси (линейная модель расстояний между тиками)
- **Слияние методов базовой линии** — Многометодное определение нулевой скорости (визуальная линия, DICOM-тег, интенсивность) для систем Samsung и GE
- **Ручной мастер в два клика** — Калибровка с прилипанием к обнаруженным тикам; авторежим никогда не перезаписывает ручную калибровку

### AI-сегментация

SonoForge использует **ONNX Runtime** для сегментации сердечных структур в реальном времени:

- **Автоматическая сегментация ЛЖ** — Нахождение контура левого желудочка в проекции A4C с помощью модели EchoNet-Dynamic (клавиша `I`)
- **Сегментация левого предсердия** — Определение границ полости левого предсердия в конечной систоле
- **AI-помощник для ЛП** — Доработка контура левого предсердия с оптическим потоком для определения границ
- **Определение митрального кольца** — AI-распознавание ключевых точек митрального клапана
- **Сглаживание по времени** — Устранение мерцания контура за счёт анализа соседних кадров (+/-2 от текущего)
- **Доработка контура** — Автоматическое привязывание контура к границам миокарда (клавиша `R`)
- **Ручной контур Simpson** — Инициализация контура по точкам митрального кольца и апекса

> Входит в полный профиль; не входит в портативную сборку **SonoForge Presenter**.

### Интеграция с DICOM и PACS

Полная DICOM-совместимость для бесшовной интеграции с больничными информационными системами:

| Протокол | Операции | Описание |
|----------|----------|----------|
| **DICOMweb (WADO-RS)** | QIDO-RS, WADO-RS, STOW-RS | HTTP-доступ к DICOM (по умолчанию) |
| **DIMSE (C-FIND)** | Поиск Study/Series/Instance | Запрос исследований в PACS |
| **DIMSE (C-GET)** | Загрузка отдельных объектов | Скачивание DICOM через DIMSE |
| **DIMSE (C-MOVE)** | Массовая загрузка серий | Перемещение объектов встроенным хранилищем |
| **DIMSE (C-STORE)** | Загрузка DICOM | Отправка локальных DICOM-файлов в PACS |
| **TLS** | Защищённые соединения | Шифрованная DIMSE-связь с проверкой сертификатов |

**Поддерживаемые PACS:** Orthanc, DCM4CHEE, Conquest и любой сервер с поддержкой DICOMweb/DIMSE.

### Клиническая отчётность и экспорт

- **Сводка по исследованию** — Комплексный отчёт со всеми измерениями, расчётами и индексированными значениями
- **Экспорт в PDF** — Клинические отчёты с информацией пациента, измерениями и референсными диапазонами
- **Референсные нормы ASE** — Встроенные таблицы нормативов для взрослой эхокардиологии (по полу и возрасту)
- **Структурированные отчёты** — Вывод в формате DICOM SR
- **Конструктор справочника** — Редактор с импортом из Excel, экспортом в PDF/HTML
- **Деидентифицированный экспорт DICOM** — Сохранение в папку после подтверждения на настоящем кадре; экспорт MP4 маскирует выжженные данные пациента так же, как просмотр

### Конструктор справочника

В SonoForge встроен **Конструктор справочников**, который позволяет собирать и поддерживать собственную библиотеку клинических справочных материалов прямо в приложении.

**Что можно добавить:**
- Таблицы рекомендаций ASE (нормы по возрасту, полу, ВТС)
- Собственные номограммы и шкалы оценки
- Чек-листы протоколов и шаблоны отчётов
- PDF-документы, изображения и структурированные данные

**Как это работает:**
- **Импорт** — Добавление справочников из Excel (.xlsx), YAML или встроенных таблиц ASE
- **Редактирование** — Изменение значений, добавление параметров и диапазонов прямо в таблице
- **Организация** — Группировка по категориям (ЛЖ, ПЖ, клапаны, педиатрия и др.)
- **Экспорт** — Обмен библиотекой в PDF или HTML с коллегами

**Веб-просмотрщик:**
Структурированный справочник открывается в быстром веб-иде (QWebEngine) с автоматическим откатом на нативный Qt-виджет:
- **Мгновенный поиск** — Поиск по всем темам, патологиям и параметрам + фильтр по возрасту
- **Инлайн-редактирование** — Правка значений прямо в таблицах с сохранением в YAML
- **Лайтбокс изображений** — Полноэкранный просмотр иллюстраций с навигацией с клавиатуры
- **Тултипы полных названий** — Наведите курсор на параметр, чтобы увидеть его полное название
- **Синхронизация тем** — Четыре CSS-темы, согласованные с тёмной/светлой темой приложения

**Расширенная библиотека:**
Помимо взрослой эхокардиографии встроенный справочник охватывает сосудистые исследования, щитовидную железу, почки, брюшную аорту и лимфоузлы — включая регургитационную фракцию для МР/АР, эхо-признаки лёгочной гипертензии, нормы 3D-ФВЛЖ/SVi и градации степени тяжести (АС/АР/ТР/ПР).

> Входит в полный профиль; не входит в портативную сборку **SonoForge Presenter**.

### Интерфейс и удобство работы

- **Тема VS Code Dark** — Цветовая схема по умолчанию, оптимизированная для длительной работы; доступны также светлая и системная темы
- **Двойной просмотр** — Сравнение двух фаз или модальностей бок о бок
- **Галерея** — Навигация по исследованиям через миниатюры
- **Воспроизведение циклов** — Плавный проигрывание cine-последовательностей с регулируемой скоростью
- **Окно/уровень** — Интерактивная настройка контрастности и яркости
- **Перекрестие** — Пространственная привязка между синхронизированными видами
- **Горячие клавиши** — Полная клавиатурная навигация для быстрой работы
- **Интернационализация (i18n)** — Поддержка русского и английского языков с переключением на лету; английский — язык по умолчанию
- **Микроанимации** — Аккордеоны, слайды панелей, crossfade вкладок, отклик кнопок и скелетоны загрузки
- **Умные оверлеи результатов** — Повторное измерение того же параметра обновляет существующее значение вместо дублирования
- **Настраиваемая раскладка** — Позиция галереи (лево/право), видимость строки состояния, режим панели активности, двойной просмотрщик
- **Закладки (вкладки исследований)** — Каждое исследование открывается в своей вкладке (клик или `Ctrl+Tab`); переключение сохраняет измерения сеанса. Включены по умолчанию, выключаются в «Настройки → Интерфейс»
- **Стартовая страница** — До первой загрузки: открыть папку, загрузить с сервера, продолжить последнюю сессию или выбрать недавнее место
- **Недавние папки и места** — Диалог «Открыть папку» помнит недавние папки и показывает известные системные места
- **Настройка панели Tools** — Настройки → Tools: свои секции, порядок секций кнопками ↑/↓, показ и скрытие инструментов
- **Масштаб интерфейса** — 100–250 % шагом 25 % или по масштабу ОС (применяется при запуске)

### Производительность и надёжность

- **Плавное воспроизведение** — Кэш кадров с вытеснением «вперёд по дуге» устраняет пропуски кадров на больших RGB-цинах; короткие цины предзагружаются полностью для бесшовного цикла
- **Неблокирующий PACS** — Асинхронные запросы исследований/серий с повторами и экспоненциальной задержкой; прерываемые таймауты скачивания (60 с)
- **Фильтры браузера сервера** — Фильтрация исследований по дате (1/3/30 дней) с корректной хронологической сортировкой
- **Кэш окна/уровня** — Кэшированные LUT-преобразования пропускают повторные загрузки кадров для отзывчивой настройки контраста
- **Общие DICOM-сессии** — Одна тёплая DICOM-сессия на файл для всех воркеров снижает потребление памяти

### SonoForge Presenter (портативное издание)

**Лёгкий профиль сборки** той же кодовой базы для демонстраций с USB-флешки — не форк:
флаги функциональности и исключения PyInstaller, основной профиль не затронут.

| | Полный SonoForge | SonoForge Presenter |
|---|---|---|
| распространение | Linux `.deb`; Windows-установщик `SonoForge-Setup-<version>-x64.exe` (и portable `SonoForge-<version>-portable.exe`); macOS Apple Silicon `SonoForge-<version>-macos-arm64.dmg` | один портативный файл (`SonoForgePresenter-<version>.exe` / `SonoForge-Presenter-<version>-x86_64.AppImage`) |
| измерения, допплер, автокалибровка | да | да |
| Strain/STE и оптический поток | да | да |
| PACS: DICOMweb + DIMSE (C-FIND/C-GET/C-MOVE/C-STORE, TLS) | да | да |
| PDF-отчёты с нормативами ASE | да | да |
| AI-сегментация (ONNX) | да | исключено из сборки |
| Конструктор справочника / веб-справочник | да | исключено из сборки |
| настройки и секреты | OS keychain + QSettings (реестр в Windows / `~/.config` в Linux) | на флешке: INI-файлы + шифрованный Fernet `secrets.ini` |
| записи вне каталога приложения | пользовательский каталог данных ОС: модели, DICOM-кэш, шрифты и журналы; QSettings/keychain остаются под управлением ОС | распаковка onefile — в системный temp; настройки, секреты, DICOM-кэш, шрифты и журналы приложения — на флешке |

В полном профиле модели, DICOM-кэш, шрифты и журналы хранятся в пользовательском
каталоге данных ОС: `%LOCALAPPDATA%\SonoForge` в Windows,
`$XDG_DATA_HOME/sonoforge` в Linux (по умолчанию `~/.local/share/sonoforge`) или
`~/Library/Application Support/SonoForge` в macOS. При первом запуске старые каталоги
моделей, кэша и журналов переносятся, если это возможно. Портативный режим имеет
приоритет и хранит данные рядом с исполняемым файлом.

- **Быстрый старт** — без первоначальной настройки и скачивания моделей, сразу в просмотрщике
- **Уменьшенный размер** — PySide6-Essentials (без QtWebEngine), без onnxruntime/PyMuPDF/openpyxl
- **Настраиваемый состав** — набор модулей это параметр сборки; AI и справочник можно вернуть позже (см. [build/presenter/README.md](build/presenter/README.md))

## Быстрый старт

> Проверить установленную версию: `sonoforge --version` (последний опубликованный релиз: **v0.3.1**; несобранные изменения перечислены в [CHANGELOG.md](CHANGELOG.md)).

### 1. Открытие DICOM-данных

- **Локальная папка:** Файл -> Открыть папку -> Выбрать директорию с DICOM/MP4/JPEG
- **Сервер PACS:** Файл -> Загрузить с сервера -> Выбрать сервер Orthanc/DICOMweb

### 2. Навигация по исследованиям

- **Галерея** -> Выбрать серию -> Кадр открывается в основном просмотрщике
- **Прокрутка** через кадры cine с помощью колёсика мыши или стрелок
- **Воспроизведение** клавишей `Space` для автоматического цикла
- **Вкладки** — Каждое исследование открывается в своей вкладке; переключение кликом по вкладке или `Ctrl+Tab`

### 3. Выполнение измерений

| Инструмент | Клавиша | Описание |
|------------|---------|----------|
| Линейный калипер | `L` | Измерение расстояния; остаётся активным для серии измерений (Dist1, Dist2, …). В зоне ROI допплера измеряет Δt (мс) + скорость (см/с или м/с) |
| Simpson биплан | `C` | Измерение объёма ЛЖ (контур по дуге) |
| M-Mode | `M` | Трассировка и измерения в M-Mode |

Контур ЛЖ (`C`) использует режим ввода, выбранный в настройках: ориентиры или свободная трасса.

### 4. Просмотр результатов

- **Панель результатов** — Все измерения с индексированными значениями (площадь тела, поправки на пол и возраст)
- **Экспорт в PDF** — Генерация клинического отчёта
- **DICOM SR** — Сохранение структурированного отчёта в PACS

## Архитектура

SonoForge построен по принципам **Clean Architecture** с чётким разделением ответственности:

```
src/echo_personal_tool/
├── domain/              # Бизнес-логика (без зависимости от Qt)
│   ├── models/          # Модели данных: контуры, допплер, M-режим
│   ├── calculations/    # Расчёты: Симпсон, Бернулли, Тейхольц
│   └── services/        # Сегментация, трекинг, справочники, золотые аннотации
├── infrastructure/      # Внешние интеграции
│   ├── dicom_*.py       # Чтение/запись DICOM (pydicom)
│   ├── orthanc_*.py     # DICOMweb клиент (httpx)
│   ├── dimse_*.py       # DIMSE клиент (pynetdicom)
│   ├── onnx_engine.py   # ONNX-инференс
│   ├── i18n.py          # Интернационализация (ru/en)
│   ├── user_preferences.py  # Настройки пользователя (QSettings)
│   ├── server_settings.py   # Управление подключениями
│   ├── profile.py       # Профили сборки (full/presenter), места portable-хранилищ
├── application/         # Слой оркестрации
│   ├── app_controller.py # Главный контроллер приложения
│   ├── frame_cache.py   # Адаптивный кэш кадров с бюджетом памяти
│   ├── workers/         # Фоновые задачи (декодирование, загрузка, ONNX и др.)
│   └── services/        # Сервисы приложения
├── presentation/        # GUI (PySide6/Qt)
│   ├── main_window.py   # Главное окно с настраиваемой раскладкой
│   ├── viewer_widget.py # Просмотрщик DICOM с оверлеями
│   ├── doppler_overlay.py # Инструменты допплера
│   ├── web_reference/   # Веб-просмотрщик справочника (QWebEngineView)
│   └── ...              # 30+ UI-компонентов
├── constructor/         # Редактор справочника
└── resources/           # Шрифты, иконки, данные ASE
```

**Профили сборки.** `infrastructure/profile.py` отдаёт активный профиль
`SONOFORGE_PROFILE=full|presenter` в виде флагов: `has_ai_segmentation()`,
`has_reference_ui()`, `portable_enabled()`. Presenter — это конфигурация сборки
того же исходного кода: защищённые необязательные импорты плюс `excludes` в
PyInstaller, поэтому состав модулей можно менять, не удаляя код.

## Безопасность и конфиденциальность

Обработка DICOM зависит от способа использования: исходные файлы из локальной папки
не копируются в управляемый кэш, но загруженные с PACS исследования сохраняются в
локальный DICOM-кэш, а запрошенные пользователем экспорты записываются в выбранное
место. Приложение не отправляет исследования в облако производителя автоматически
и не отправляет аналитику/телеметрию. Поддержка протокола DICOM и использование
клинических справочных значений сами по себе не определяют регуляторный статус,
наличие сертификации безопасности или соответствие требованиям конкретного
развёртывания.

### Функции безопасности и ограничения

- **Проверка DICOM-файлов** — Проверка перед парсингом (магические байты, ограничение размера)
- **Проверка DICOM UID** — Отклонение UID из одних точек, длиннее 64 символов, с точками в начале/конце (PS3.5 раздел 6.1)
- **Контроль моделей** — SHA256-проверка ONNX-моделей при загрузке; повреждённые модели блокируются
- **Экспериментальное сохранение измерений** — Локальное хранение измерений и роста/веса; по умолчанию выключено (Настройки → Другое; требуется перезапуск). Записи содержат медицинские данные, не шифруются и остаются до явного удаления; очистка DICOM-кэша их не затрагивает. Восстановление, экспорт/импорт и ограничения описаны в [справке](docs/HELP_RU.md).
- **Управляемый PACS-кэш** — Лимит записи 20 ГиБ на один запущенный экземпляр; превышающая лимит загрузка отклоняется без вытеснения сессий, параллельные экземпляры не координируются
- **Срок хранения кэша** — По умолчанию очистка при обычном выходе; при запуске удаляются сессии старше 7 дней; Settings позволяет удалить неактивные сессии вручную
- **Защита кэша** — DICOM в кэше не шифруется приложением; на POSIX для файлов применяется режим `0600`, а в Windows наследуются ACL каталога. Для защиты данных на диске используйте шифрование ОС/тома
- **Сетевая передача** — Для удалённых DICOMweb-узлов HTTPS не принудителен; проверка сертификата по умолчанию включена для HTTPS. DIMSE TLS необязателен и по умолчанию выключен
- **Диагностика** — UID сокращаются, а чувствительные DICOM-теги фильтруются, но журналы не являются полным аудитом и их нужно проверять перед передачей
- **Шифрованные portable-секреты (Presenter)** — Токены паролей PACS шифруются рядом с исполняемым файлом; это не шифрует DICOM-кэш и экспорты

Подробнее: [SECURITY.md](SECURITY.md) и [инвентарь данных](docs/security/data-inventory.md) с описанием потоков данных, хранения и ответственности при развёртывании.
